# Python 환경 전환과 실행 검증

`migrate_python_patch.py`는 2026-10-20에 기존 심화 미션 환경을 Python **3.12.13의 정확한 설치 경로**로 전환하기 위해 만든 도구다. `02_Advanced`의 기존 환경만 대상으로 하며 프로젝트별로 하나씩 실행한다. 사용 중인 해당 환경의 Python·노트북 커널을 종료한 상태에서 사용한다.

```powershell
# codsaid 저장소 루트에서, 설치된 Python 3.12.13으로 실행
<Python-3.12.13-경로> -B tools/migrate_python_patch.py A1-1
```

전환 전 패키지 목록·버전 선택·`pyproject.toml`과 `uv.lock` 해시를 보존한다. 기존 `.venv`를 작업공간의 `.newlearn/tmp/learning-python31213/<미션>`에 임시 보관하고, `.python-version`과 `uv venv --python`에 `3.12.13`을 지정한다. `uv sync --locked`로 복원한 뒤 패키지 목록이 전후 동일한지 검사한다. 패키지 차이·검사 실패가 있으면 이전 환경과 버전 선택 파일을 복구한다. 이미 정확한 패치 경로를 쓰는 환경은 다시 만들지 않고 같은 검증을 수행한다.

복원은 기본적으로 오프라인이다. 필요한 고정 패키지가 캐시에 없을 때 `--allow-download`를 명시하면 잠금 파일에 기록된 패키지만 내려받는다. Python 다운로드와 잠금 파일 갱신은 허용하지 않는다. 실패한 시도의 기록은 남기며, 복구 상태를 확인한 뒤 `--attempt 2`처럼 새 시도 번호를 사용한다.

검증은 다음을 포함한다.

- 실제 Python 패치 버전과 기반 경로, 패키지 이름·버전, 의존성 호환성.
- 프로젝트에 포함된 `unittest` 전체.
- `verify_python_runtime.py`를 통한 실제 분석·이미지/영상 처리·검색·모델 학습 및 추론. 시간과 출력이 큰 프로젝트는 축소한 검증 범위를 결과에 명시한다.
- 노트북 의존성이 있는 A1-1·A2-1·A5-1·A5-2에서는 현재 인터프리터로 실제 Jupyter 커널을 시작해 코드 실행.

환경별 기록은 해당 미션의 `environment/<날짜>-python31213*`에 남는다. 전후 목록·설정, 실행 명령·종료 코드, 테스트·실행 로그와 `verification.json`을 함께 기록한다. 2026-10-20 전환 기록은 커밋 `597bfca`에 보존하고 현재 트리에서는 제거했다([전환 결과](../docs/python-environment-migration-2026-10-20.md)). 기존 보고서·노트북을 덮어쓰지 않도록 실행 검증 출력은 임시 폴더로 보낸다. 모든 검증이 끝난 뒤 완료 작업을 작업공간 캐시 정리 도구에 등록해 이전 환경과 임시 출력을 정리한다. 공유 uv 캐시는 같은 패키지의 재설치에 쓰므로 유지한다.
