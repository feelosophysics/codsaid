## 1. OS View
OS를 한 가지 정의로 묶으면 애플리케이션과 하드웨어 사이의 중재자입니다. 그러나 그 중재자는 보는 각도에 따라 여러 얼굴을 드러냅니다.

- 구성으로 보면 User Application / Distribution / Kernel / Hardware 의 4계층입니다.
- 수칙으로 보면 커널은 Never Die / Own Device / Co-Work 의 세 원칙을 따릅니다.
- 메커니즘으로 보면 코드의 내용에 구애받지 않고 절차에 따라 실행하는 agnostic 시스템입니다.
- 주체로 보면 User / System / Control 의 세 관점이 동시에 성립합니다.
- 시간으로 보면 Build time은 컴파일러가, Runtime은 OS가 책임집니다.

이 다섯 축을 같이 들고 있어야 OS라는 단어가 모호하지 않게 잡힙니다. 이후 글에서는 각 축을 하나씩 더 깊이 파고들 예정입니다.

## 2. OS Kernel

#### 2.1 커널의 진짜 정체
> 커널 = 메모리에 항상 올라가 있는 코드 + 전역 상태의 집합

#### 2.2 커널을 이루는 두 가지 — 코드와 데이터
커널은 실행 중인 하나의 프로그램이라기보다는, 필요할 때마다 호출되는 코드의 집합

#### 2.3 CPU는 하나의 흐름만 실행한다
커널 코드와 사용자 코드는 번갈아 가며 실행됩니다.

#### 2.4 커널은 평소에 실행되지 않는다
커널은 항상 돌고 있는 존재가 아니라, 필요할 때(시스템 콜, 인터럽트, 예외)마다 실행 흐름 위에 올라오는 코드

#### 2.5 실행은 순간적이지만 상태는 영구적이다
커널 코드는 짧게 깨어났다가 곧 잠듭니다. 그러나 그 동안 만들어 둔 상태는 커널이 잠든 사이에도 메모리에 그대로 유지됩니다. 다음에 커널이 깨어나면 그 상태를 그대로 이어받아 작업을 계속합니다.

이 구조 덕분에 커널은 강력한 shared state를 유지하는 시스템으로 동작할 수 있습니다. 프로세스 테이블, 파일 디스크립터 테이블, 메모리 매핑 정보 — 모두 커널이 실행되지 않는 시간 동안에도 살아 있는 자료구조입니다.

#### 2.6 멀티코어에서의 커널
커널 내부에는 **동기화 메커니즘**이 반드시 들어갑니다. 이 동기화는 단순히 있으면 좋은 것이 아니라 없으면 시스템이 망가지는 것입니다. 멀티코어 시대의 커널은 본질적으로 동시성 프로그래밍의 결정체입니다.
- **Lock**: 한 번에 한 코어만 특정 자료구조에 접근하도록 잠그는 방식
- **Per-CPU data**: 코어마다 별도의 데이터를 두어 충돌을 원천적으로 회피
- **Atomic 연산**: 중간에 끊기지 않는 단일 명령으로 원자적으로 변경

#### 2.7 커널의 하드웨어 제어 — Own Device의 실제 구현
1. 요청 — 사용자는 직접 디스크에 접근하지 않는다
2. 명령 — 커널만이 하드웨어에 명령할 수 있다
3. 비동기 대기 — CPU와 디스크는 독립적으로 동작한다
4. 알림 — 하드웨어가 끝나면 인터럽트로 통보한다
5. 복구 — 데이터를 전달하고 사용자 모드로 돌아간다

#### 2.8 정리 — 첫 글과의 연결
지난 글(OS View)에서 커널을 다음 세 가지로 묶었습니다.

- Never Die — 어떤 상황에서도 중단되지 않아야 한다
- Own Device — 모든 하드웨어를 직접 제어한다
- System Co-Work — 프로세스 간 협력을 가능하게 한다

이번 글에서 본 내용을 다시 위 세 원칙에 대응시켜 보면 자연스럽게 들어맞습니다.

- Never Die는 커널이 메모리에 항상 상주하며 전역 상태가 영구적으로 유지되는 구조에서 보장됩니다.
- Own Device는 user mode / kernel mode 분리, 특권 명령, ISR을 통한 인터럽트 처리로 구현됩니다.
- System Co-Work는 멀티코어 커널의 동기화 메커니즘과 프로세스 테이블 같은 shared state를 통해 가능해집니다.

다시 말해, 첫 글에서 추상적인 원칙으로 다룬 것이 이번 글에서 구체적인 메커니즘으로 풀린 셈입니다.

다음 글에서는 커널이 관리해야 할 자원 중 가장 기본인 메모리를 다룹니다. 저장장치 계층 구조부터 캐싱, 가상 메모리까지 이어집니다.
