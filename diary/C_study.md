## 2. Binary
- "노이즈 마진(noise margin)이 크다" 고 합니다. 2진수는 노이즈 마진이 가장 큰 방식입니다.
- 트랜지스터는 본질적으로 아주 작은 전기 스위치. CPU에서 가장 많이 쓰이는 트랜지스터는 MOSFET 이라는 종류
    - Source(소스): 전류가 들어오는 쪽
    - Drain(드레인): 전류가 나가는 쪽
    - Gate(게이트): 문을 여닫는 손잡이
- 논리 게이트: 트랜지스터 하나로는 그냥 스위치일 뿐입니다. 그런데 여러 개를 잘 연결하면 "생각하는 부품" 이 됩니다. 이걸 논리 게이트(Logic Gate) 라고 합니다.
- 안정화: 전기 신호는 빛의 속도에 가깝지만, 그래도 시간이 걸립니다. 또 처음에는 전압이 흔들흔들합니다. 회로는 이 흔들림이 가라앉아서 명확히 0이나 1로 자리잡을 때까지 잠깐 기다립니다. 이게 안정화
- 플립플롭은 "값을 기억하는 작은 방"입니다. 다음 클럭이 와도 그 값을 유지하고 있다가, CPU가 필요로 할 때 꺼내 줍니다.

## 3. CPU
- opcode가 디코더의 배선과 만나서, 전기가 자연히 흘러갈 길을 따라가는 것뿐
- ISA(Instruction Set Architecture): "이 CPU가 어떤 opcode에 어떤 동작을 하기로 약속했는가"의 명세서

의미
```text
┌────────────────────────────────────────────┐
│ 인간의 의도 ("두 수를 더하고 싶다")          │ ← 의미가 가장 풍부
├────────────────────────────────────────────┤
│ 고급 언어 (C, Python)                        │
│  - 변수, 타입, 함수 등으로 의미 표현         │
├────────────────────────────────────────────┤
│ 컴파일러                                     │ ← 의미를 소진하며 번역
│  - 의미를 "사용해서" opcode 시퀀스 생성      │
├────────────────────────────────────────────┤
│ ISA (계약서)                                 │ ← 의미가 표준화됨
│  - opcode ↔ 동작의 공식 매핑                │
├────────────────────────────────────────────┤
│ 마이크로아키텍처                              │ ← 의미가 구조로 굳음
│  - 디코더, 마이크로코드, 파이프라인          │
├────────────────────────────────────────────┤
│ 회로 (Frozen Wiring)                         │ ← 의미가 물리로 완전히 굳음
│  - 트랜지스터 배치, 게이트 연결              │
├────────────────────────────────────────────┤
│ 실행 시점의 CPU                              │ ← 의미가 0 (semantic silence)
│  - 그저 전압이 흐를 뿐                       │
└────────────────────────────────────────────┘
```

## 4. Memory Model
- stack은 보통 8mb로 작기 때문에, 지역 변수에 큰 배열을 잡으면 안됨(int arr[10000000] 같은 것)
- C 표준에 따르면 arr[i]는 컴파일러가 *(arr + i)로 번역. 2[arr];   // 30 (!!) 왜냐하면 2[arr]도 컴파일러가 *(2 + arr)로 번역하기 때문입니다. 덧셈은 교환법칙이 성립하니까 결과가 같습니다.
- C 컴파일러는 함수 인자에서 배열을 항상 포인터로 변환합니다. 그래서 함수 안에서 sizeof(arr)를 하면 배열 크기가 아니라 포인터 크기(8바이트) 가 나옵니다. 그래서 C에서는 배열을 함수에 넘길 때 크기를 따로 인자로 같이 넘기는 게 관례입니다. void print_array(int *arr, size_t n) { ... }
