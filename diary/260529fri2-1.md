## word

- transaction: '거래/매매' 또는 '작업 단위'라는 뜻 / 데이터베이스의 상태를 변화시키기 위해 수행하는 논리적 작업의 단위
    - 예시: 계좌 이체 시 '내 계좌에서 출금'과 '상대방 계좌에 입금'이라는 두 가지 과정을 묶어, 둘 다 성공하거나 둘 다 취소되어야 하는 하나의 완벽한 작업 처리 과정

- decorator: 원본 코드나 객체를 직접 수정하지 않고도, 그 위에 새로운 기능이나 속성을 마치 장식처럼 덧붙여 확장할 수 있게 해주는 디자인 패턴이나 문법
    - 파이썬: @ 기호를 사용하여 기존 함수를 감싸고, 어떤 함수를 실행하기 **전(Before)**이나 **후(After)**에 특정한 동작을 추가하고 싶을 때, 원래 함수 코드를 건드리지 않고 겉에 '포장지'를 씌우는 기술

- Schema: '계획', '도식', '구조'를 뜻하는 말로, 데이터베이스, 인공지능(AI), 심리학 등 다양한 분야에서 쓰이며 어떤 대상이나 정보를 이해하기 위한 구조화된 틀이나 개념

- Aspect: 어떤 사물이나 상황을 바라보는 측면, 양상, 또는 관점
    - 프로그래밍에서 Aspect-Oriented(관점 지향)는 핵심 비즈니스 로직과 공통 부가 기능을 분리하여, 코드의 중복을 줄이고 유지보수성을 높이는 소프트웨어 개발 방법론(AOP: Aspect-Oriented Programming)을 뜻

- 직렬화(Serialization)는 컴퓨터 메모리(RAM)에 있는 객체나 데이터 구조를 파일로 저장하거나 네트워크로 전송하기 위해 바이트(Byte) 또는 문자열(JSON, XML 등) 형식으로 변환하는 과정입니다.
- 역직렬화(Deserialization)는 직렬화된 데이터를 다시 원래의 메모리 객체나 데이터 구조로 되돌리는 과정입니다.

- yield: 문맥에 따라 크게 '생산하다(산출하다)', '(수익을) 내다', '(권리를) 양보하다/굴복하다'의 뜻을 가짐.
    - 키워드 (yield): 파이썬(Python) 등에서 함수를 종료하지 않고 값을 반환(생성)할 때 사용하는 제너레이터(Generator) 관련 명령어

- Orphaned: 고아가 된, 부모를 잃은
    - (기술/IT) 연결이 끊긴, 방치된: 문맥에 따라 상위 시스템이나 연결 고리를 잃어 더 이상 유지보수되지 않는 데이터나 프로세스를 의미

- fallback: 원래의 방법이 실패하거나 문제가 발생했을 때, 이를 대신하여 작동하는 '대체 방안' 또는 '대비책(플랜 B)'

- Entity: ‘독립적으로 존재하는 실체나 개체’
    - IT 및 데이터베이스 (DB): 데이터 모델링에서 가장 자주 쓰이는 개념으로, 정보화하여 저장하고 관리할 필요가 있는 현실 세계의 '어떤 것(객체)'을 의미
        - 예: 사람, 사물, 장소, 사건, 개념 등

- pros and cons: 장점과 단점

- 샤딩(Sharding): 거대한 데이터베이스나 네트워크를 '샤드(Shard)'라 불리는 작은 조각으로 나누어 분산 저장하고 처리하는 기술.

- Deflate: '(공기·가스를) 빼다, (풍선 등이) 오므라들다'
    - 무손실 압축 알고리즘: ZIP, GZIP, PNG 파일 포맷 등에서 사용되는 데이터 압축 방식을 뜻합니다
