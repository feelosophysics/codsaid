0. 이 자료를 쓰는 법 — 탑다운 학습 전략

세부 수학부터 쌓지 않고 "모델이 한 번 배우는 과정"이라는 완성된 그림에서 출발한다. 모르는 부품이 나오면 그때 그 부품으로 내려간다.

  1. 큰 그림 (20분) — 1장의 학습 루프와 2장의 위젯에서 "1 스텝 학습"을 여러 번 눌러 본다. 손실이 왜 줄어드는지 말로 설명할 수 있으면 통과다. 세부 수식은 아직 몰라도 된다.
  2. 부품 분해 (장당 20–40분) — 3–10장의 위젯마다 예측 상자가 있다. 슬라이더를 움직이기 전에 결과를 먼저 예측하고 확인한다. 틀린 예측이 가장 많이 배우는 지점이다.
  3. 손계산 (60–90분, 종이와 계산기) — 7장 연습지에서 고정 예제를 손으로 풀고 채점한다. "새 문제"로 숫자를 바꿔 한 번 더 푼다. 행렬식·Power Iteration 2회·소프트맥스도 손으로 해 본다.
  4. 코드 대조 (60분) — 11장에서 각 수식이 어느 함수 어느 줄인지 확인하고, tests/test_requirements.py가 요구사항을 어떻게 검사하는지 읽는다. 노트북을 처음부터 실행한다.
  5. 설명 연습 — 13장의 다섯 질문에 답을 보지 않고 1분씩 말로 설명한다. 막히면 해당 장으로 돌아간다.
왜 탑다운인가. 고유값·연쇄 법칙·MLE를 따로 외우면 "이걸 왜 배우지?"에서 멈춘다. 학습 루프라는 목적을 먼저 잡으면 각 개념이 루프의 어느 칸을 채우는 부품인지 분명해지고, 부품 사이의 연결(예: Sigmoid+BCE의 기울기 ŷ − y가 역전파와 MLE 양쪽에서 똑같이 나오는 것)이 보인다.

1. 큰 그림 — 학습은 네 칸짜리 반복이다

신경망 학습은 "예측 → 얼마나 틀렸나 → 누구 탓인가 → 조금 고치기"의 반복이다. 이 미션의 모든 모듈이 이 네 칸 중 하나를 맡는다. 칸을 누르면 해당 장으로 이동한다.

칸이 미션에서 만드는 것핵심 질문
① 순전파행렬 변환 시각화, 행렬식, Power Iteration, SVD행렬을 곱하면 공간이 어떻게 변하나?
② 손실분포 시각화, 소프트맥스, MSE/CE ↔ MLE 유도손실 공식은 어디서 왔나?
③ 역전파수치 미분, Gradient 시각화, 2층 신경망 역전파 손계산각 가중치가 손실에 얼마나 책임이 있나?
④ 갱신VanillaGD, Momentum (+Adam, Newton), 수렴 경로얼마나, 어떤 방향으로 고쳐야 빨리 수렴하나?
SVD와 고유값은 루프 안에서 직접 쓰이기보다 "행렬이 공간을 어떻게 늘리고 줄이는가"를 해석하는 도구다. 가중치 행렬의 주요 방향, 데이터 압축(PCA), 저랭크 근사(LoRA 같은 미세조정 기법)의 바탕이 된다.

2. 학습 한 스텝을 끝까지 따라가기

미션의 고정 예제 신경망(입력 2 → 은닉 2 → 출력 1, Sigmoid, BCE)이다. 숫자는 모두 실제 계산이다. 이 장이 이후 모든 장의 "목적지"다.

학습 루프 시뮬레이터 필수 3
예측 x₂ = 0인 동안 W1의 두 번째 열(0.2, 0.4)은 학습해도 바뀔까? "10 스텝"을 누르기 전에 답하고 확인하라. 이유는 7장 ∂L/∂W1 = outer(∂L/∂z1, x)에 있다.
이 위젯 한 번 클릭 안에 미션 전체가 들어 있다: 행렬 곱(W1 @ x) → Sigmoid와 BCE(베르누이 MLE) → 연쇄 법칙으로 기울기 → 경사하강법으로 갱신.

3. 행렬 곱 = 공간 변형, 행렬식 = 면적 배율

2×2 행렬 A는 평면의 모든 점을 옮긴다. 기저 벡터 e₁=(1,0)은 A의 1열로, e₂=(0,1)은 2열로 간다. 이것만 알면 그림 전체를 예측할 수 있다.

행렬 변환 실험실 필수 1
A = [[a, b], [c, d]]
예측 전단 Sh(1)은 원을 비스듬히 찌그러뜨린다. 면적은 커질까 작아질까? det를 계산해 보고 버튼을 눌러라.

왜 |det A|가 면적 배율인가

단위 정사각형(넓이 1)은 e₁, e₂가 만드는 도형이다. 변환 후에는 A의 두 열 (a, c), (b, d)가 만드는 평행사변형이 되고, 그 넓이가 |ad − bc|다. 선형 변환은 평면 전체에 같은 배율을 적용하므로 원·삼각형·어떤 도형이든 넓이가 |det A|배가 된다.

det [[a, b], [c, d]] = ad − bc 부호가 음수면 방향(시계/반시계)이 뒤집힘, 0이면 평면이 선으로 납작해짐

코드는 단위 원을 100개 점의 다각형으로 만들고 신발끈 공식으로 변환 전후 넓이를 구해 비교한다. 다각형도 "도형"이므로 비율은 근사가 아니라 정확히 |det|다. 다각형 넓이 자체는 π보다 약간 작다(3.1395).

Area = ½ |Σᵢ (xᵢ yᵢ₊₁ − xᵢ₊₁ yᵢ)|
함정. 미션의 세 변환(회전, S(2, 0.5), Sh(k))은 모두 det = 1이다. 면적비 1 = det 1만 보면 관계를 제대로 확인한 것이 아니다. 그래서 구현은 det = 5, det = −2인 행렬로도 확인한다(run_all.py의 transforms_extra, 테스트).

신경망의 z = W₁x도 같은 일이다. 은닉층은 입력 공간을 늘이고, 비틀고, 회전한 뒤 Sigmoid로 휘게 만든다. 층을 쌓는다는 것은 이런 변형을 이어 붙이는 것이다.

4. 고유벡터와 Power Iteration

대부분의 벡터는 A를 곱하면 방향이 바뀐다. 고유벡터는 방향이 그대로이고 길이만 λ배가 되는 특별한 방향이다: Av = λv.

Power Iteration 단계 실행 필수 1
예측 λ가 3과 2.9로 거의 같은 행렬과, 3과 1로 차이가 큰 행렬 중 어느 쪽이 더 빨리 수렴할까? 90° 회전 행렬에서는 무슨 일이 생길까?

왜 반복하면 가장 큰 고유벡터로 모이나

시작 벡터를 고유벡터로 분해하면 b₀ = c₁v₁ + c₂v₂. A를 t번 곱하면

Aᵗb₀ = c₁λ₁ᵗ v₁ + c₂λ₂ᵗ v₂ = λ₁ᵗ ( c₁v₁ + c₂(λ₂/λ₁)ᵗ v₂ )

|λ₂/λ₁| < 1이면 두 번째 항이 매번 그 비율만큼 줄어 v₁ 방향만 남는다. 매 단계 길이를 1로 정규화하는 것은 숫자가 폭발하지 않게 하려는 것뿐이다. 고유값은 Rayleigh 몫 λ ≈ bᵀAb로 읽는다. 대칭 행렬에서는 이 오차가 (λ₂/λ₁)²ᵗ로 줄어 더 빠르다. A=[[4,1],[1,3]]는 비율 0.516이라 23회 만에 tol 1e-6을 만족한다.

실패 조건. ① |λ₁| = |λ₂|이면 (예: 회전 행렬의 복소 고유값, λ = 3과 −3) 한 방향이 이기지 못한다. ② 시작 벡터가 v₁과 정확히 직교하면 c₁ = 0이라 v₁이 나타나지 않는다(실제로는 반올림 오차가 구해 준다). 구현은 무작위 시작 벡터(seed 42)를 쓰고, 수렴 여부를 converged로 반환한다.

검증 규칙: 고유값 계산 자체에는 np.linalg.eig를 쓰지 않고, compare_with_numpy_eig에서 결과 비교에만 쓴다. 오차 3.8e-11%로 5% 기준을 통과했다.

5. SVD — 이미지를 "중요한 층"의 합으로 쪼개기

모든 행렬은 A = UΣVᵀ = Σᵢ σᵢ uᵢ vᵢᵀ로 쓸 수 있다. 각 항 σᵢuᵢvᵢᵀ는 rank-1 "층"이고, σᵢ가 그 층의 중요도다. 큰 σ부터 k개만 더하면 압축이다.

SVD 압축 슬라이더 필수 1
원본 128×128
k개 층의 합
예측 k=1 이미지는 어떻게 생겼을까? (힌트: u₁v₁ᵀ의 모든 행은 v₁의 배수다.) k를 얼마로 하면 원본보다 저장 공간이 커질까?
저장 비율 = k(m + n + 1) / (mn) U의 m·k + σ의 k + V의 n·k 개 숫자

128×128에서는 k < 63.75일 때만 실제로 줄어든다. k=100은 화질이 거의 원본(PSNR 54 dB)이지만 저장량은 1.57배라 "압축"이 아니다. 64×64 이미지는 rank가 최대 64라서 k=100이 아예 불가능하다. 그래서 이 구현은 128×128을 썼다.

Eckart–Young 정리. 상위 k개 층의 합 A_k는 rank가 k 이하인 모든 행렬 중 원본과의 오차(Frobenius)가 가장 작다. 오차는 버린 특이값으로 정해진다: ‖A − A_k‖ = √(σ²ₖ₊₁ + … + σ²ₙ). 테스트 test_svd_matches_eckart_young_error가 이 식을 직접 확인한다.

6. 미분과 Gradient — "어느 쪽으로 가면 손실이 커지나"

미분은 입력을 아주 조금 바꿨을 때 출력이 바뀌는 비율이다. 컴퓨터는 극한을 못 하므로 작은 h로 근사한다.

전진차분 f′(x) ≈ [f(x+h) − f(x)] / h 오차 O(h)
중심차분 f′(x) ≈ [f(x+h) − f(x−h)] / 2h 오차 O(h²) — 테일러 전개에서 h² 항이 상쇄
h를 줄이면 무조건 정확해질까? 필수 2
예측 h를 1e-15까지 줄이면 오차가 어떻게 될까? 이유는 "거의 같은 두 수의 뺄셈"에 있다.

h가 크면 절단 오차(테일러 고차항), 너무 작으면 반올림 오차(float64의 유효숫자 약 16자리가 뺄셈에서 사라짐, 크기 ≈ ε/h)가 지배한다. 중심차분은 h ≈ 1e-5 근처에서 오차가 가장 작다. 구현의 기본값 h=1e-5는 여기서 나온 값이다. x²에서는 절단 오차가 정확히 0이라 오차 3.9e-11은 전부 반올림 오차다.

Gradient는 등고선에 수직이다

등고선 위 아무 점이나 눌러 보기 필수 2

등고선 위에서 접선 방향 t로 아주 조금 움직이면 f가 변하지 않는다: f(p + εt) − f(p) ≈ ε ∇f·t = 0. 따라서 ∇f ⊥ t다. 위젯은 접선을 타원의 매개변수식에서, Gradient를 중심차분에서 따로 구한 뒤 cos를 계산한다. 코드의 gradient_contour_orthogonality도 같은 방식이다.

그림 함정. 축 비율이 다르면(x축 1칸 ≠ y축 1칸) 수직인 화살표가 비스듬해 보인다. 그래서 시각화 함수는 ax.set_aspect("equal")을 쓴다.
학습과의 연결. −∇L은 손실이 가장 빨리 줄어드는 방향이다. 경사하강법은 이 방향으로 한 걸음씩 걷는다. 역전파는 수백만 개 파라미터의 ∇L을 한 번에 효율적으로 구하는 방법이다. 수치 미분은 파라미터마다 손실을 두 번 계산해야 해서 느리다. 그래서 수치 미분은 역전파 결과를 검증하는 데 쓴다(7장).

7. 역전파 — 연쇄 법칙으로 "책임" 나누기

L은 W1에 직접 의존하지 않는다. W1 → z1 → a1 → z2 → ŷ → L 사슬을 거친다. 연쇄 법칙은 사슬의 각 고리에서 국소 미분을 곱한다. 역전파는 이것을 출력에서 입력 방향으로 한 번만 계산하고 재사용한다.

순전파 (shape 포함)

z₁ = W₁x + b₁ (2,) = (2,2)(2,) + (2,)
a₁ = σ(z₁) (2,)
z₂ = W₂·a₁ + b₂ () = (2,)·(2,) + ()
ŷ = σ(z₂) ()
L = −[y log ŷ + (1−y) log(1−ŷ)] ()

역전파 유도

  1. ∂L/∂ŷ = −y/ŷ + (1−y)/(1−ŷ) () — log의 미분 (log u)′ = 1/u.
  2. σ′(z) = σ(z)(1−σ(z)) — σ = (1+e⁻ᶻ)⁻¹을 미분하면 e⁻ᶻ/(1+e⁻ᶻ)² = σ·(1−σ).
  3. ∂L/∂z₂ = ∂L/∂ŷ · ŷ(1−ŷ) = ŷ − y () ✔ 체크포인트 — 분모 ŷ, (1−ŷ)가 약분된다. 출력층의 기울기는 "예측 − 정답"이다.
  4. ∂L/∂W₂ = ∂L/∂z₂ · a₁ (2,), ∂L/∂b₂ = ∂L/∂z₂ — z₂ = Σ W₂ᵢa₁ᵢ + b₂ 이므로 ∂z₂/∂W₂ᵢ = a₁ᵢ.
  5. ∂L/∂a₁ = ∂L/∂z₂ · W₂ (2,) — 오차가 가중치를 따라 거꾸로 나뉜다. 큰 가중치로 연결된 뉴런이 더 큰 책임을 진다.
  6. ∂L/∂z₁ = ∂L/∂a₁ ⊙ a₁(1−a₁) (2,) ✔ 체크포인트 — a₁ᵢ는 z₁ᵢ에만 의존하므로 원소별 곱.
  7. ∂L/∂W₁ = outer(∂L/∂z₁, x) (2,2), ∂L/∂b₁ = ∂L/∂z₁ — ∂z₁ᵢ/∂W₁[i,j] = xⱼ. "뒤에서 온 오차 × 앞에서 온 입력".
shape 규칙. ∂L/∂(값)의 shape은 그 값의 shape과 같다. 갱신 W ← W − η∂L/∂W가 성립하려면 당연하다. 유도 중 shape이 안 맞으면 전치나 외적을 빼먹은 것이다.

손계산 연습지

종이에 풀고 소수점 4자리로 입력 필수 3
손계산 팁 (막힐 때만 열기)
  • σ(z)는 계산기로 1/(1+e^(−z)). 중간값은 소수점 6자리로 들고 다니고 마지막에 4자리로 반올림한다. 4자리로 반올림한 값을 다음 단계에 쓰면 마지막 자리가 1 정도 틀릴 수 있다.
  • ∂L/∂z₂는 ŷ − y로 바로 구하고, ∂L/∂ŷ·ŷ(1−ŷ)로 검산한다.
  • x₂ = 0이면 W₁의 두 번째 열 기울기는 바로 0이다.
  • 미션 결과 예시의 ∂L/∂z₁ 두 번째 값 −0.0513은 오타로 보인다. −0.2116 × 0.2445 = −0.0517이고 NumPy와 수치 미분도 −0.0517이다.

노트북 notebooks/backprop_derivation.ipynb는 같은 표를 Markdown으로 적고, 순수 NumPy·모듈 구현·수치 미분 세 방법으로 같은 값을 얻는지 확인한다(최대 차이 1.1e-11).

8. 최적화 — 얼마나, 어떤 방향으로 고칠까

경사하강법은 θ ← θ − η∇f(θ). 학습률 η가 너무 작으면 느리고, 너무 크면 골짜기를 넘어 튕겨 나간다. 화면을 누르면 시작점이 바뀐다.

옵티마이저 실험실 필수 4 보너스 Adam·Newton

학습률의 안정 조건

x² + y²에서 ∇f = (2x, 2y)이므로 한 스텝은 x ← x − η·2x = (1 − 2η)x다. 매 스텝 |1 − 2η|배가 된다.

미션 문장 검토. "lr=0.5 이상에서 발산"은 x² + y²에서는 성립하지 않는다. 경계는 η = 1이다. 일반 규칙은 η < 2 / (가장 큰 곡률)이다. x² + y²의 곡률은 2라서 η < 1, x² + 10y²의 곡률은 20이라서 η < 0.1이다. 구현은 실제 경계를 보여 주고, 발산 그래프는 η = 1.1과 "x² + 10y²의 η = 0.5"로 제시한다(outputs/11_lr_divergence.png).

Momentum은 언제 이득인가

v ← βv + ∇f(θ), θ ← θ − ηv

v는 과거 기울기의 누적이다. 같은 방향이 계속되면 속도가 붙고(최대 약 1/(1−β) = 10배), 부호가 번갈아 바뀌는 성분은 서로 상쇄된다. 실험 결과는 생각보다 미묘하다.

η가 작으면 GD는 완만한 x 방향에서 거의 움직이지 못한다. 이때 Momentum이 크게 이긴다. 그러나 η를 GD의 한계(0.1) 가까이 키우면 GD가 더 빠르다. β = 0.9인 Momentum의 수렴률은 약 √β ≈ 0.95에서 더 좋아지지 않는다. β = 0.9는 조건수(최대/최소 곡률)가 1000 이상인 골짜기에 맞는 값이다. 조건수 10인 이 문제에서는 관성이 과해 소용돌이친다.

정리. 실제 신경망의 손실 지형은 조건수가 매우 크고, η는 가장 가파른 방향 때문에 작게 잡을 수밖에 없다. 그 상황에서 Momentum이 평평한 방향을 가속한다. "Momentum이 항상 빠르다"가 아니라 "작은 η에서 평평한 방향을 가속한다"가 정확한 설명이다.

보너스: Adam과 Newton

Adam: m ← β₁m + (1−β₁)g, v ← β₂v + (1−β₂)g², θ ← θ − η m̂ / (√v̂ + ε)

Adam은 좌표마다 기울기 크기 √v로 나눈다. 그래서 첫 스텝은 곡률과 상관없이 좌표마다 약 η만큼 움직인다. x²+10y²에서 η = 0.1이면 GD는 y 방향에서 영원히 진동한다(1 − 20·0.1 = −1). Adam은 144회 만에 1e-3에 도달한다. 같은 η로 두 함수에서 경로가 똑같다는 점도 확인해 보라. 좌표별 스케일에 둔감하다는 것이 "적응적 학습률"의 효과다.

Newton: θ ← θ − H⁻¹∇f 2차 테일러 근사의 최저점으로 바로 이동

이차 함수에서는 한 번에 최저점에 간다. Rosenbrock에서도 5회 만에 도달한다(GD η = 0.001은 17,695회). 대가는 ① n×n Hessian을 구하고 풀어야 하는 비용(파라미터 백만 개면 10¹²개 원소)과 ② 안장점에 끌려가는 성질이다. x² − y²에서 Newton은 안장점 (0,0)으로 곧장 간다. GD는 −y 방향의 기울기를 따라 안장점에서 탈출한다.

9. 확률 분포와 손실 함수 — 손실은 "가정"에서 나온다

"데이터가 어떤 분포에서 나왔다고 가정하는가"를 정하면, 그 데이터가 관측될 확률(우도)을 최대로 만드는 것이 손실을 최소로 만드는 것과 같아진다.

정규분포 PDF 두 개 비교 필수 5

N(2, 0.5)의 0.5는 분산이다(표준편차 0.707). 폭이 좁아지면 넓이 1을 유지하려고 봉우리가 높아진다. 확률밀도는 확률이 아니므로 1을 넘을 수 있다. 분산을 0.1로 줄여 확인해 보라.

베르누이 PMF 두 개 비교 필수 5

MSE 최소화 = 정규분포 가정의 MLE

  1. 가정 y = f(x) + ε, ε ~ N(0, σ²) → p(y|x) = (2πσ²)^(−½) exp(−(y − f(x))² / 2σ²)
  2. 우도 독립이면 Πᵢ p(yᵢ|xᵢ). log는 증가 함수라 최대점이 같고 곱을 합으로 바꾼다 → Σᵢ log p(yᵢ|xᵢ)
  3. 대입 Σ log p = −(1/2σ²) Σ (yᵢ − f(xᵢ))² − (n/2) log(2πσ²)
  4. 상수 제거 둘째 항은 θ와 무관, 양수 1/2σ²와 1/n을 곱해도 최적점 불변, 부호를 바꾸면 max → min
  5. 결론 argmax Σ log p = argmin (1/n) Σ (yᵢ − f(xᵢ))² = argmin MSE
w를 움직여 MSE와 음의 로그우도 비교 필수 5
예측 가정한 σ²를 바꾸면 NLL 곡선의 최저점 위치가 움직일까? 높이는?

Cross-Entropy 최소화 = 베르누이/카테고리 분포 가정의 MLE

  1. 가정 y ∈ {0,1}, y ~ Bernoulli(ŷ) → p(y|x) = ŷʸ(1 − ŷ)¹⁻ʸ (y=1이면 ŷ, y=0이면 1−ŷ만 남는 압축 표기)
  2. 로그우도 Σᵢ [yᵢ log ŷᵢ + (1 − yᵢ) log(1 − ŷᵢ)]
  3. 부호 반전 → 그대로 BCE. 버릴 상수조차 없다.
  4. 다중 클래스 one-hot y, ŷ = softmax(z) → p(y|x) = Π_c ŷ_c^(y_c) → −Σ log p = −Σᵢ Σ_c y_ic log ŷ_ic = Categorical CE. 정답 클래스 확률의 −log만 남는다.
2장과의 연결. 2장 신경망의 손실 BCE는 "정답이 확률 ŷ인 베르누이에서 나왔다"는 가정의 음의 로그우도다. 그리고 Sigmoid + BCE의 logit 기울기 ŷ − y는 7장 ∂L/∂z₂와 같은 식이다. MSE를 쓰면 기울기에 σ′(z)가 곱해진다. 그래서 확신을 갖고 틀린 경우(ŷ ≈ 0, y = 1) 기울기가 사라져 학습이 멈춘다.
소프트맥스 필수 5
예측 모든 logit에 똑같이 +3을 더하면 확률이 바뀔까? 온도 T를 0.1로 낮추면?

softmax(z)ᵢ = e^(zᵢ) / Σⱼ e^(zⱼ). 모든 z에서 같은 상수를 빼도 결과가 같다. 그래서 구현은 max(z)를 빼서 e¹⁰⁰⁰ overflow를 막는다(softmax([1000, 1001, 1002])도 정상). 출력 합과 1의 차이는 0으로 1e-6 기준을 통과했다.

10. 보너스 — 정보 이론으로 다시 보기

엔트로피는 분포의 불확실성, Cross-Entropy는 "모델 q로 실제 p를 설명하는 비용", KL은 그 추가 비용이다.

H(p) = −Σ pᵢ log pᵢ, H(p, q) = −Σ pᵢ log qᵢ, KL(p‖q) = Σ pᵢ log(pᵢ/qᵢ) ≥ 0
H(p, q) = H(p) + KL(p‖q)
베르누이 p(실제)와 q(모델) 보너스 3

학습 중 정답 분포 p는 고정이라 H(p)는 상수다. 따라서 Cross-Entropy 최소화 = KL 최소화 = MLE. one-hot 정답이면 H(p) = 0이라 CE = KL = −log q[정답]이다. KL은 대칭이 아니다(KL(p‖q) = 0.1838 ≠ KL(q‖p) = 0.1920, p=[0.7,0.2,0.1], q=[0.4,0.4,0.2]). 그래서 거리(distance)가 아니라 발산(divergence)이라 부른다.

13. 자기 점검 — 미션 목표 5문항

답을 열기 전에 1분 동안 소리 내어 설명해 본다. 막히면 괄호의 장으로 돌아간다.

Q1. 행렬 곱셈은 공간을 어떻게 변형하고, 행렬식은 면적 변화와 어떻게 연결되나? (3장)

행렬은 기저 벡터 e₁, e₂를 자기 열벡터로 보내고, 나머지 점은 그 선형 결합대로 따라간다. 그래서 격자는 평행사변형 격자가 되고 원은 타원이 된다. 단위 정사각형이 두 열벡터의 평행사변형이 되므로 넓이 배율은 |ad − bc| = |det A|다. 선형이라 모든 도형에 같은 배율이 적용된다. 음수면 방향이 뒤집히고, 0이면 평면이 선이나 점으로 납작해져 역변환이 없다.

Q2. 고유값·고유벡터의 의미와 SVD를 이용한 압축 원리는? (4–5장)

고유벡터는 변환 후에도 방향이 유지되는 방향이고, 고유값은 그 방향의 배율이다. A를 반복해 곱하면 가장 큰 |λ| 방향이 (λ₂/λ₁)ᵗ 비율로 다른 성분을 압도하므로 Power Iteration으로 구할 수 있다. SVD는 임의의 행렬을 중요도 σᵢ 순의 rank-1 층 σᵢuᵢvᵢᵀ로 분해한다. 큰 σ 몇 개만 남기면 최소 오차의 저랭크 근사(Eckart–Young)가 된다. k(m+n+1) < mn일 때만 저장량이 줄어든다.

Q3. 2층 신경망의 역전파를 유도하고 손계산할 수 있나? (7장)

출력에서 시작해 국소 미분을 곱해 내려간다. ∂L/∂z₂ = ŷ − y, ∂L/∂W₂ = ∂L/∂z₂·a₁, ∂L/∂a₁ = ∂L/∂z₂·W₂, ∂L/∂z₁ = ∂L/∂a₁ ⊙ a₁(1−a₁), ∂L/∂W₁ = outer(∂L/∂z₁, x). 고정 예제는 ∂L/∂z₂ = −0.3527, ∂L/∂z₁ = [−0.0440, −0.0517], ∂L/∂W₁ = [[−0.0440, 0], [−0.0517, 0]]이다. 7장 연습지를 답 없이 풀 수 있으면 통과다.

Q4. MSE와 Cross-Entropy의 확률적 의미 차이와 MLE 연결은? (9–10장)

MSE는 "타깃 = 예측 + 정규 잡음" 가정의 음의 로그우도에서 상수를 뺀 것이고, 회귀에 맞는다. Cross-Entropy는 "타깃 ~ 베르누이/카테고리(모델 확률)" 가정의 음의 로그우도 그 자체이고, 분류에 맞는다. 둘 다 MLE이며 가정한 분포만 다르다. CE = H(p) + KL(p‖q)이므로 CE 최소화는 모델 분포를 데이터 분포에 맞추는 것이다.

Q5. Learning Rate와 Momentum이 수렴에 미치는 영향을 실험 결과로 설명하면? (8장)

이차 함수에서 GD는 방향마다 |1 − η·곡률|배가 되므로 η < 2/최대곡률이어야 수렴한다. x²+y²는 η < 1이고, η=0.5는 한 번에 도착, η=1.1은 발산한다. x²+10y²는 η < 0.1이다. 작은 η에서는 평평한 방향이 느리고(η=0.01에서 100회 후 0.663), Momentum β=0.9는 기울기를 누적해 25배 가까이 간다(0.026). 그러나 η가 한계에 가까우면 β=0.9의 과한 관성 때문에 GD보다 느리다(√β ≈ 0.95 수렴률). Adam은 좌표별로 기울기를 정규화해 곡률 차이에 둔감하다.

자주 틀리는 포인트

  • N(2, 0.5)의 0.5를 표준편차로 읽기 → 분산이다.
  • ∂L/∂W₁을 outer(x, ∂L/∂z₁)로 쓰기 → shape은 같은 (2,2)지만 전치된 답이다. z₁ = W₁x에서 W₁[i,j]는 입력 j → 은닉 i 연결이다.
  • det = 1인 변환만으로 "면적비 = det"를 확인했다고 생각하기.
  • "Momentum은 항상 빠르다", "lr=0.5면 발산한다"처럼 조건 없는 문장.
  • SVD k=100이 128×128 이미지를 "압축"했다고 말하기 → 저장량 1.57배.
