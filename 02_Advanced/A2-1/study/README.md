# A2-1 HTML 학습 자료

`a2-1.html` 하나를 브라우저에서 열면 인터넷 없이 읽고 조작할 수 있다. 결과 그림, SVD 데이터, Python 소스 발췌를 모두 파일 안에 넣었다. 휴대폰 화면 폭에서도 읽을 수 있게 구성했다.

## 학습 시작

실제 계산과 시연은 [역전파·학습](../notebooks/backprop_derivation.ipynb) → [확률·손실](../notebooks/probability_loss.ipynb) 순서로 진행한다. 두 노트북은 각각 독립 실행 가능하며 작은 입력, 중간값, 클래스 상태와 기존 모듈 대조를 포함한다. 이 HTML은 파라미터를 조작하는 보조 자료로 사용한다. 내장 코드는 작성 시점의 사본이다.

## HTML 열람 순서

학습 루프 전체를 먼저 보고 각 수학 부품으로 내려가는 탑다운 순서다.

1. **큰 그림**: 0–2장. 학습 루프 네 칸과 "1 스텝 학습" 위젯
2. **부품 분해**: 3–10장. 위젯마다 예측한 뒤 조작해 확인한다.
3. **손계산**: 7장 연습지. 고정 예제와 무작위 문제를 채점한다.
4. **코드 대조**: 11장 코드 지도. 요구사항, 함수, 테스트를 연결한다. 문법과 데이터 흐름은 [코드 읽기 가이드](code-walkthrough.md)와 `src/` 주석으로 따라간다.
5. **설명 연습**: 13장의 미션 목표 5문항

## 포함 내용

- 위젯 13개
  - 학습 루프 시뮬레이터
  - 행렬 변환
  - Power Iteration 단계 실행
  - SVD k 슬라이더
  - 수치 미분 오차
  - Gradient와 등고선
  - 역전파 손계산 연습지
  - 옵티마이저 실험실 (프리셋 11개)
  - 정규분포
  - 베르누이
  - MSE와 NLL 비교
  - 소프트맥스
  - 정보 이론
- 원본 코드 발췌 24개와 실제 줄 번호
- `outputs/` 결과 그림 15개 축소본
- 자기 점검 질문 5개, 자주 틀리는 포인트, 해석 결정 메모

[`code-walkthrough.md`](code-walkthrough.md)는 HTML과 별도인 Markdown 문서다. 빌드 대상이 아니며, 소스 줄 번호 링크를 담고 있어 소스를 고치면 링크도 함께 확인해야 한다.

페이지는 Python을 실행하지 않는다. 선택한 계산을 JavaScript로 재현한다. 연습지의 "새 문제"는 무작위로 만들고, 정답은 같은 JavaScript 계산 함수로 구한다.

## 작성 당시 검증

이 HTML은 작성 당시의 소스·결과를 담은 자료다. 아래 수치 대조는 그 사본에 대한 확인 범위이며, 현재 Python 실행은 노트북과 `src/`를 따른다.

다음을 확인했다.

- **코드 발췌**: 발췌가 현재 원본 줄과 같은지 확인한다.
- **페이지 구조**: 내부 링크 대상, 입력 요소의 레이블, 외부 리소스를 쓰지 않는지 확인한다.
- **계산 대조**: HTML의 `<script id="mathlib">`를 Node.js로 실행해 Python 구현과 152개 값을 비교한다.
  - 신경망 7개
  - 면적 5개
  - Power Iteration 3개
  - 소프트맥스 3개
  - 분포 5개
  - 정보량 3개
  - 옵티마이저 경로 11개
  - SVD 3개

SVD 위젯은 float32 분해 결과를 쓴다. 그래서 상대 오차는 2e-4, PSNR은 0.2% 이내에서 Python과 일치한다. 그 밖의 계산은 1e-9 이내로 일치한다. 그림 그리기와 화면 배치는 대조 대상이 아니며, 데스크톱과 375px 폭 브라우저에서 수동으로 확인했다.
