# A4-2 글에서 정보와 기분 뽑기: 규칙으로 언어를 정의할 수 있을까?

고객 문의나 리뷰 문장에서 연락처, 날짜, 금액을 뽑고, 글쓴이의 기분이 좋은지 나쁜지 판단하는 프로그램을 만드는 미션이에요. 학습된 모델 없이 사람이 쓴 규칙만 써요. 글자 모양은 **정규표현식**(글자 패턴을 적는 표기법)으로 찾고, 기분은 **감성 사전**(단어별 점수표)으로 계산해요.

## 문장을 넣으면 이렇게 나와요

```text
입력: 문의: support@example.com, 전화 02-0000-0002 일시: 2024년 3월 15일, 참가비: 50,000원

- 이메일: support@example.com
- 전화: 02-0000-0002
- 날짜: 2024-03-15
- 금액: 50000
```

```text
입력: 이 식당은 정말 맛있지 않았어요

감성 단어: 맛있(+2)
부정어: 않(×-1)
강조어: 정말(×1.5)

계산: (+2) × (-1) × 1.5 = -3
판정: 부정
```

## 결론: 규칙으로 어디까지 됐을까?

**형식이 정해진 값은 규칙으로 대부분 찾았지만, 기분은 단어에 드러난 만큼만 알 수 있었어요.**

| 하는 일 | 결과 |
| --- | --- |
| 이메일, 전화번호, 날짜, 금액, URL 찾기 | 직접 쓴 시험 문장의 정답 88개 중 77개를 찾았고, 찾은 82개 중 77개가 맞았어요 (F1 0.906) |
| 기분 판단 (긍정, 부정) | 영화 리뷰 1,000건 중 762건을 맞혔어요 (정확도 76.2%) |

규칙이 찾은 것은 대체로 맞고, 판정 이유도 계산식으로 설명할 수 있어요. 대신 규칙을 만들 때 생각하지 못한 표현은 놓쳐요.

두 점수 모두 실제 고객 문의로 잰 값은 아니에요. 값 찾기는 직접 쓴 문장, 기분 판단은 네이버 영화 리뷰(NSMC)로 쟀어요.

## 어떻게 동작할까?

**값 찾기:** 정규표현식으로 모양이 맞는 후보를 찾아요. 그다음 코드가 `2월 30일`처럼 없는 날짜를 버리고, `2024-03-15`처럼 형식을 통일해요.

**기분 판단:** 단어마다 -3(매우 나쁨)부터 +3(매우 좋음)까지 점수를 적어 두었어요. 문장에서 찾은 단어의 점수에 아래 규칙을 곱한 뒤 모두 더해요. 합이 0보다 크면 긍정, 그렇지 않으면 부정이에요.

| 규칙 | 하는 일 | 예 |
| --- | --- | --- |
| 부정어 | 점수를 뒤집어요 | `좋지 않다`: (+2) × (-1) = -2 |
| 강조어 | 점수를 키워요 | `정말 좋다`: (+2) × 1.5 = +3 |
| 이중부정 | 두 번 뒤집어 원래대로 돌아와요 | `재미있지 않을 수 없다`: (+2) × (-1) × (-1) = +2 |

## 어디서 틀릴까?

틀린 영화 리뷰 238건 중 120건은 사전에 있는 단어가 하나도 없는 긍정 리뷰였어요. 단서가 없어 점수가 0이면 부정으로 판정하기 때문이에요. 나머지는 아래처럼 글자만 봐서 생긴 오류가 많아요.

| 문장 | 무엇을 잘못 읽었나 |
| --- | --- |
| `공일공-공공공공-공공공일` | 한글로 쓴 숫자를 전화번호로 찾지 못해요 |
| `만원 버스` | 사람이 가득 찬 버스를 10,000원으로 읽어요 |
| `소망합니다` | 안에 든 `망합`을 `망하다`로 읽어요 |
| `결코 잊을 수 없는 영화` | 칭찬인데 `없`을 부정어로 읽어요 |
| `눈물짜내기의 끝판왕.` | 비꼬는 말의 점수를 그대로 더해요 |
| `음식은 맛있는데 가격이 비싸요` | 좋은 점과 나쁜 점이 상쇄돼 0점이 돼요 |
| `문제가 없어요` | `문제`는 사전에 없어서 `없`만 남아 부정이 돼요 |

## 언제 규칙을 쓰면 좋을까?

| 상황 | 알맞은 쪽 |
| --- | --- |
| 연락처, 날짜, 금액처럼 형식이 정해진 값 찾기 | 규칙 |
| 정답 달린 데이터가 거의 없거나 판정 이유를 설명해야 할 때 | 규칙, 또는 규칙과 통계 함께 쓰기 |
| 정답 달린 데이터가 수천 건 이상이고 표현이 다양할 때 | 통계 |

같은 영화 리뷰로 비교하면, 학습 리뷰가 10건일 때 통계 방법(TF-IDF)의 정확도는 54.1%로 규칙(76.2%)에 크게 못 미쳐요. 약 3,000건부터는 통계 방법이 규칙을 넘어요(77.5%).

## 실행하기

[uv](https://docs.astral.sh/uv/getting-started/installation/)가 필요해요. 없다면 `pip install uv`로 설치할 수 있어요.

```bash
cd 02_Advanced/A4-2
uv sync --locked
uv run python main.py --text "이 식당은 정말 맛있지 않았어요"
```

`uv sync`는 Python 3.12와 라이브러리를 이 폴더의 `.venv`에 설치해요. 처음 한 번은 내려받는 데 시간이 걸리고, 약 340MB를 차지해요.

- **전체 평가 다시 재기:** `uv run python -m src.run_all`을 실행하면 결과가 `outputs/`에 저장돼요. 1~2분 걸리고, 처음 실행할 때 NSMC(약 19MB)와 KNU 감성사전(약 1MB)을 내려받아요.
- **uv 없이 실행:** `pip install -r requirements.txt`로 설치한 뒤, 위 명령의 `uv run python`을 `python`으로 바꾸세요.

<details>
<summary>규칙 상세</summary>

**값 찾기**

| 찾는 값 | 찾을 수 있는 표기 | 이렇게 통일해요 |
| --- | --- | --- |
| 이메일 | `user@example.com`, `user.name@sub.example.com` | 도메인만 소문자로 |
| 전화번호 | `010-0000-0001`, `02-000-0001`, `01000000001`, `+82 10-…` | `010-0000-0001` 형식으로 |
| 날짜 | `2024년 1월 15일`, `2024/01/15`, `24.12.25`, `3월 15일` | `2024-01-15` 형식으로 |
| 금액 | `10,000원`, `1억 2천만원`, `$100`, `오천원` | 정수로. 원화는 원, 달러는 센트 단위 |
| URL | `https://…?q=v`, `www.naver.com` | 앞부분을 소문자로, `www.`만 있으면 `http://`를 붙여서 |

값이 서로 겹치면 더 긴 쪽을 택해요. 찾은 값은 감성 계산 전에 가려서, 날짜 속 숫자나 마침표가 계산을 방해하지 않게 해요.

**감성 사전:** 직접 만든 394개 단어를 써요. 그중 92개는 `발연기`, `불친절하`처럼 영화나 고객 응대에서 자주 쓰는 말이에요. 37배 큰 KNU 사전으로 바꾸면 정확도가 67.8%로 8%포인트쯤 떨어져서, 사전은 크기보다 쓰는 영역에 맞는지가 더 중요했어요.

**적용 범위**

- **강조어(× 1.2~1.5)와 약화어(× 0.5):** 감성어 앞, 같은 절 안, 2어절 이내에서만 적용해요.
- **앞에 오는 부정어(안, 못):** 같은 어절에 붙었거나 바로 앞 어절일 때 적용해요.
- **뒤에 오는 부정어(않, 없, 아니 등):** 감성어 뒤, 같은 절 안, 3어절 이내에서 다음 감성어가 나오기 전까지 적용해요.

**확장 규칙:** 미션 필수 범위 밖에서 네 가지를 더 넣었어요.

1. **이모티콘:** 같은 글자 반복은 2개로 줄여 비교해요. `ㅋㅋㅋㅋ`는 `ㅋㅋ`로 봐요.
2. **대조:** `지만`, `하지만`, `근데` 앞 절은 × 0.5, 뒤 절은 × 1.5를 해요.
3. **꾸밀 말이 없는 부정어:** `이건 아니다`처럼 감성어가 없으면 -1을 줘요.
4. **평점 언급:** `1점`, `별 한 개`는 -2, `10점`은 +2를 줘요. `10점 만점에`는 제외해요.

**고객 문의 문장** (점수로 잰 결과는 아니에요)

| 문장 | 점수 | 원인 |
| --- | ---: | --- |
| `택배가 도착했습니다` | +1 | `도착했`의 `착했`을 `착하다`로 읽었어요 |
| `문제가 없어요` | -1 | `문제`가 사전에 없어서 `없`만 남았어요 |
| `이보다 좋을 수 없다` | -2 | 최고라는 뜻인데 `없`이 `좋`을 뒤집었어요 |

**개선 아이디어**

1. **형태소 분석기 쓰기:** `소망합니다`의 `망합` 같은 오탐을 줄일 수 있어요.
2. **관용구 등록하기:** `잊을 수 없는`처럼 칭찬하는 표현을 사전에 넣어요.
3. **단서 없는 문장은 통계 모델에 맡기기:** 0점 리뷰를 무조건 부정으로 판정하지 않게 돼요.
4. **한글 숫자를 먼저 바꾸기:** `공일공`을 `010`으로 바꾼 뒤 같은 패턴을 써요.
5. **앞뒤 단어 보기:** `만원 버스`의 `버스`처럼 주변 말로 뜻을 가려요.

**개인정보 마스킹(`--mask`):** 주민등록번호, 카드번호, 주소, 전화번호, 이메일 정답 20개를 잘못 가린 것 없이 가렸지만 3개를 놓쳤어요. 놓친 값은 곧 유출이라서 재현율이 중요해요.
