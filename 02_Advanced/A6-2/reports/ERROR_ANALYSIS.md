# 오차 분석 리포트 (Error Analysis)

모델이 틀린 Test 사진에 원인 태그 초안을 달고 사람이 검수하는 흐름이다(Human-in-the-loop). 태깅 도구 `tools/build_tagging_page.py`는 오분류 사진 옆에 실제 클래스와 예측 클래스의 Train 사진을 3장씩 나란히 보여 준다.

**검수 상태: 0/42건 검수 완료.** 검수 전 행은 Claude가 사진을 직접 보고 단 초안(tagged_by = claude-draft)이며 사용자 검수를 기다린다. 검수는 `annotations/tagging.html`에서 한다.

원인 태그는 관찰에서 세운 가설이다. Test 오분류를 보고 선택한 처방의 같은 Test 재평가는 탐색적이며 독립 Test 검증이 아니다.

## 분석 대상

주 모델(20장·전체, 전체 Fine-tuning)의 Test 오분류는 8건이다. 미션 기준 30건에 못 미쳐, 같은 Test 사진에서 다음 모델들의 오분류를 합쳤다: 20장·전체, 20장·부분, 20장·LP, 10장·전체, 10장·부분, 10장·LP, 5장·전체. 각 행의 '틀린 모델' 열에 어떤 모델이 틀렸는지 적었고, 예측·신뢰도는 목록에서 먼저 나온 모델(주 모델 우선)의 값이다. 여러 모델이 함께 틀린 사진일수록 데이터 쪽 원인일 가능성이 크다. 분석 대상은 오분류 사진 42장이다.

## 사진을 보며 찾은 실패 패턴

1. **민들레 ↔ 머위가 23건(55%)**: 둘 다 노란 방사형 꽃이다. 사람은 머위의 붉은 비늘 줄기, 꽃이 잎보다 먼저 피는 점, 민들레의 톱니 잎과 매끈한 줄기로 구별한다. 그런데 꽃만 크게 찍힌 사진에서는 이 단서가 화면 밖에 있다. 줄기가 보이는 옆모습 사진(#7, #19)도 틀렸다. 모델이 줄기보다 꽃잎 질감과 색에 의존한다는 뜻이다.
2. **배경 편향**: 머위 Train 사진은 맨흙·자갈·낙엽 위가 많고, 민들레는 잔디 위가 많다. 자갈·낙엽 위의 민들레와 맨흙 위의 가자니아가 머위로 예측됐다(세부 태그 '배경 편향' 5건). 꽃이 아니라 배경을 학습한 흔적이다.
3. **짙은 꽃판 = 해바라기·루드베키아**: 꽃판이 짙은 금잔화·가자니아가 해바라기·루드베키아·오스테오스페르뭄으로 간 경우가 7건이다. 색 대비가 강한 중심부가 이 클래스들의 대표 특징으로 학습됐다.
4. **사진 품질**: 워터마크·글자 6건, 작게 찍히거나 여러 송이가 있는 사진 11건. Test 안에 거의 같은 금잔화 사진 두 장(test_4201, test_4211)이 있어 둘 다 틀렸다.

## 증강·개선 전략

| 우선순위 | 대상 패턴 | 전략 | 근거 |
| --- | --- | --- | --- |
| 1 | 민들레↔머위 (클래스 유사성) | 더 깊은 층까지 미세 조정 + 224px 입력, 두 클래스의 줄기·잎이 보이는 사진 보강 | 가장 많은 원인. 구별 단서(비늘 줄기·잎)가 작고 세밀해 해상도와 상위 층 특징이 필요하다 |
| 2 | 배경 편향 | RandomResizedCrop 범위 확대(꽃 위주로 자르기), 배경 교체·합성, 다양한 배경의 사진 수집 | 배경이 클래스 단서가 되지 않도록 배경과 클래스의 상관을 끊는다 |
| 3 | 짙은 꽃판 | ColorJitter(색조·채도) 약하게 | 중심부 색 하나에만 의존하지 않게 한다. 색이 실제 구별 단서인 클래스도 있어 약하게만 쓴다 |
| 4 | 워터마크·작은 객체 | RandomErasing(가림), 작은 크롭 비율 | 글자·가림에 둔감하게 |
| 5 | 중복 사진 | Train·Validation·Test 사이 근접 중복 검사(perceptual hash) | 평가가 같은 사진을 두 번 세지 않게 |

이번 미션에서는 1순위 처방을 실제로 적용해 효과를 쟀다(아래 '처방과 효과'). 2~5순위는 전략으로만 남긴다.
