# 같은 고객, 두 가지 예측

초보자에게 같은 입력이라도 예측할 정답에 따라 출력과 평가가 달라짐을 설명하는 Figure급 시각 장치다. 작은 고객 카드 판독기에 원본 변수 6개를 제시하고, 두 개의 선형 계측기가 독립적으로 신용 점수(0~1000)와 연체 예측 점수(0~1)를 표시한다. 사용자가 Test 고객을 바꾸면 두 계측기의 표시자가 해당 고객의 실제 모델 출력으로 움직인다.

고객을 고른 뒤 ‘두 모델로 예측’, ‘정답 공개’ 순서로 시연한다. 공개 전에는 두 타깃을 입력 카드에 포함하지 않는다. 공개 후 회귀는 실제 신용 점수와 예측의 차이, 분류는 실제 연체 여부와 임계값 0.5의 판정을 비교한다. 정답 공개는 이미 완료한 Test 예측을 설명하는 연출이며, 화면 조작으로 모델을 학습하는 기능은 아니다.

두 모델은 연결된 직렬 장치가 아니다. 분류는 회귀 출력이나 실제 신용 점수를 입력받지 않는다. 또한 연체 예측 점수가 개인의 검증된 실제 확률이라고 주장하지 않는다. 화면은 선택한 고객 1명의 사례와 Test 전체 지표를 구분한다.

## 부품
- 바닥판·상판·받침 발 4개·모서리 나사 4개: 10
- 입력 판독기 받침·본체·홈 2개·카드·카드 지지대·인레이 6개: 12
- 계측기 2개: 받침 2개·눈금판·상하 안내 레일 2개·끝막이 2개·체결 나사 4개: 각 11, 합계 22
- 예측 표시자 2개: 슬라이더·표식·덮개: 각 3, 합계 6
- 회귀 정답 표시자: 슬라이더·표식: 2
- 분류 임계값 표식·명판·정비 패널·나사 4개: 7

총 59개 안팎의 실제 부품. 색상 대신 눈금과 위치·외부 범례로 의미를 구분한다. 모델 설명과 조작 안내는 그림 바깥에 둔다. 바닥·각 받침·계측기 판·레일·표시자의 실제 접촉과 깊이 순서를 같은 형상으로 검증한다.
