# A5-1 임계값 분류기 — Figure

## 개념
고정된 RF + class_weight 모델의 예측 점수 p와 임계값 t를 비교한다. p ≥ t이면 연체로 예측한다. 검사선만 움직이며 모델과 고객의 실제 라벨은 바뀌지 않는다. 모델의 출력은 보정된 실제 연체 확률이라는 보장이 없어 화면에서 ‘예측 점수’로 부른다.

## 장치
0~1 눈금 위의 고객 카드와, 같은 눈금을 따라 움직이는 문형 검사대. 검사대 오른쪽(점수 이상)이 연체 예측 구역이다. 선택한 카드는 Test 고객 한 명이며, 혼동 행렬과 지표는 Test 2,000명 전체에서 계산한다. 기계가 예측 모델 자체라는 오해를 막기 위해 이미 계산된 점수에 판정 기준을 적용하는 장치임을 설명한다.

## 부품 목록 (Figure, 40~80개)
- 기반: 받침 발 4개, 바닥판, 상판, 모서리 고정 나사 4개, 명판 (11)
- 구조: 앞뒤 레일 2개, 레일 받침 4개, 끝막이 4개, 체결 나사 8개 (18)
- 눈금: 눈금판, 0~1 주 눈금 11개, 보조 눈금 40개. 눈금은 부품 수에 미포함 (1)
- 검사대: 슬라이더 발 2개, 지주 2개, 가로대, 상부 덮개, 손잡이 받침, 손잡이, 손잡이 홈 6개, 체결 나사 4개 (18)
- 고객: 카드 안내 레일, 카드 받침, 카드 본체, 라벨 인레이, 상태 표식 (5)
- 기반의 정비 패널, 정비 패널 체결 나사 4개, 통풍 슬롯 5개 (10)

주요 고체 약 63개. 모든 나사·손잡이는 사각 가공 부품이며 배관·케이블·회전체 없음. 기하 감사는 같은 실제 형상으로 기록하고 기본 임계값, 양 끝, 이동 중 위치에서 검사한다.

## 비교
같은 저장소의 기존 학습 자료 원본에 연결하고, 동일 모델·임계값의 지표를 대조한다. 0.2 → 0.5 → 0.8에서 예상하고 조작한 뒤 자기 말로 설명한다. Test를 조작하는 교육용 실험이며 운영 임계값 선택으로 사용하지 않는다.
