# A1-1 HTML 학습 자료

`a1-1.html` 하나를 브라우저에서 열면 인터넷 없이 읽고 조작할 수 있다. 그림·데이터·Python 소스 사본을 모두 파일에 포함했다. 외부 참고 링크를 누를 때만 네트워크가 필요하다.

처음에는 01 전체 흐름 → 02 한 행의 의미 → 07 RFM 계산을 읽고, 이후 03–06 전처리와 08–12 해석·소스 탐색으로 진행한다. 질문 체크는 스스로 설명해봤다는 표시이며 자동 채점이나 학습 효과 검증이 아니다. 새로 열면 초기화된다.

Python을 처음 익힌다면 **01 → 03 → 02 → 04–08 → 09–12 → 보너스** 순서도 좋다.
`src/`의 6개 파일에는 한국어 Google 스타일 docstring과 학습용 주석을 포함했다.
새 문법은 처음 나오는 곳에서 자세히 설명하고, 코드 덩어리의 목적·데이터 모양·해석 범위를 연결한다.
함수 인자가 없거나 반환하지 않으면 빈 Args/Returns 항목을 만들지 않는다.

각 장과 보너스 3종에는 **문법 → 데이터 변화 → 존재 이유 → 작은 예제 → 확인 질문**을 추가했다.
확인 질문은 설명을 생각해본 뒤 답을 펼치는 용도다. 기존 체크 질문 12개와 추가 설명 질문 15개를 구분한다.
현재 학습·시연은 [`../notebooks/analysis_report.ipynb`](../notebooks/analysis_report.ipynb)를 중심으로 진행한다. 작은 입력과 실제 데이터의 중간 계산을 실행하고 클래스의 결과와 대조할 수 있다. 이 HTML은 배열과 정책을 조작해 보는 보조 자료다.

배경 설명 원본은 `learning-notes.json`이다. HTML에는 이 설명이 15개 학습 패널로 들어 있고, 작성 당시의 주석 포함 Python 소스도 함께 들어 있다.
`tools/`는 실행·생성 도구이며, 우선 읽을 분석 구현은 `src/`와 노트북이다.

## 포함 내용

- 학습 장 12개, 예측·설명 질문 12개
- 원본에서 자동 발췌한 코드 18개와 실제 줄 번호
- 7개 Python 파일의 전체 소스 탐색, 함수·클래스·줄 번호 이동
- 실행 단계별 입력·출력 상태 비교
- 상품 단위 vs 판매 행 단위 결측치 대치 비교
- 이미지 픽셀 밝기·변동과 평균·표준편차 조작
- IQR 경계·이상치 후보·클리핑 비교
- 작은 거래의 기준일 변경과 고유 주문 수 vs 행 수 비교
- 실제 합성 고객 240명의 그룹 기준 변경·판정 경로
- Python에서 생성한 실제 차트 6개와 해석

작은 설명 예제, 테스트의 작은 금액, 실제 seed=42 분석 결과를 구분해 표시한다. 합성 데이터의 인사이트는 실제 시장 결론이나 캠페인 효과의 증거가 아니다. 페이지는 Python을 실행하지 않고 선택한 계산을 JavaScript로 재현한다.

## 작성 당시 검증

이 HTML은 작성 당시의 소스·결과로 한 번 만든 학습 자료다. 생성 도구와 템플릿은 정리했고, 아래는 작성 당시 확인한 내용이다.

작성 당시 내장 소스, 18개 코드 발췌, 내부 링크·요소 참조·입력 레이블, 8개 내장 PNG를 검사했다. 실제 Python 로직으로 계산한 예제 근거를 Node.js에서 HTML의 계산 함수로 다시 계산해 비교했다. 비교 사례는 25개이고, 고객 240명의 R·F·M 점수와 기본 그룹도 모두 대조했다.

브라우저에서는 데스크톱·320px·390px에서 화면과 주요 조작을 확인했다. 이는 수동 브라우저 관찰이며 자동 CLI 실행 검증과 구분한다. 인쇄용 CSS는 포함했지만 PDF 출력 품질은 별도로 검증하지 않았다.

보너스 절은 NumPy 이미지 피처, 가입 월별 코호트(미관측 월 마스킹), 오프라인 Plotly RFM을 포함한다. 라이브러리는 iframe의 srcdoc에 포함되고 외부 CDN을 요청하지 않는다. 코호트 표와 그림·차트는 results/bonus의 결과와 해시로 대조했다.
