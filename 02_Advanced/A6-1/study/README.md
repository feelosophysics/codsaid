# A6-1 HTML 학습 자료

`a6-1.html` 하나를 브라우저에서 열면 인터넷 없이 읽고 조작할 수 있다. 결과 그림, 코드 발췌, 실행 로그, MNIST 원본 바이트가 모두 파일 안에 들어 있다. 휴대폰 화면 폭(375px)에서도 읽을 수 있다.

## 학습 순서

완성된 학습 루프를 먼저 보고 부품으로 내려가는 탑다운 순서다.

1. **큰 그림**: 0–1장을 읽고, 8장 XOR 실험실에서 초기화를 바꿔 학습해 본다.
2. **엔진 내부**: 2장 계산 그래프를 한 단계씩 실행한다. 3장 미분 규칙을 코드와 대조한다.
3. **손계산**: 4장 연습지에서 2-2-1 망의 순전파·역전파 21칸을 손으로 채우고 채점한다. "새 문제"로 반복한다.
4. **검증과 실험**: 5장 ε 실험, 7장 깊은 망 신호 전파 실험실, 실제 실험 결과
5. **코드 대조와 설명 연습**: 13장 코드 지도, 14장 미션 목표 5문항

## 포함 내용

- 위젯 11개
  - 계산 그래프 단계 실행
  - 역전파 손계산 연습지 (고정 예제와 무작위 문제)
  - 수치 미분 ε 실험 (절단 오차와 반올림 오차)
  - 활성화 함수와 도함수
  - Softmax 야코비안
  - 깊은 망 신호 전파 (깊이·폭·활성화별 Random/He/Xavier)
  - XOR 학습 실험실 (초기화·손실·옵티마이저·학습률·폭·seed, seed 20개 일괄 실행)
  - MNIST IDX 헤더와 첫 이미지
  - Dropout 마스크
  - 학습 루프 지도, 테마 전환
- 원본 코드 발췌 19개 (실제 줄 번호)
- `figures/` 결과 그림 6개 축소본
- 자기 점검 질문 5개, 자주 틀리는 포인트, 해석 메모

페이지는 Python을 실행하지 않는다. 필요한 계산은 `<script id="mathlib">`의 JavaScript가 minigrad와 같은 순서로 다시 계산한다. 위젯의 난수열은 NumPy와 다르다. 그래서 같은 seed 번호라도 Python 실험과 초기 가중치가 다르고, 성공률 같은 통계만 비슷하게 나온다.

## 재생성과 검증

상위 A6-1 폴더에서 실행한다.

```powershell
uv run python scripts/run_all.py
uv run python tools/build_study_guide.py
uv run python tools/verify_study_guide.py
```

`a6-1.template.html`이 설명과 화면의 편집 원본이다. 빌드 도구는 여기에 현재 소스의 발췌, `figures/` 그림, gradient check 로그 발췌, MNIST 첫 24바이트와 첫 이미지를 넣는다. 그리고 `source-manifest.json`에 원본 해시를 저장한다. 본문 표의 수치는 자동으로 갱신되지 않는다. 실험 조건을 바꾸면 본문도 다시 확인해야 한다.

검증 도구는 다음을 확인한다. Node.js가 필요하다.

- **파일 대조**: 매니페스트 해시와 현재 파일을 비교한다. 텍스트는 LF로 정규화해서 비교한다.
- **코드 발췌**: HTML 속 발췌가 현재 원본 줄과 같은지 확인한다.
- **페이지 구조**: 내부 링크 대상, 입력 요소의 레이블, 스크립트가 찾는 id, 외부 리소스를 쓰지 않는지 확인한다.
- **계산 대조**: mathlib을 Node.js로 실행해 minigrad와 비교한다.
  - XOR 학습 곡선 6개 (He, Random 성공·clip 실패·안정형 회복, Xavier, Zero). 같은 초기 가중치에서 101개 loss가 상대 1e-9 이내로 일치한다. 실제 차이는 1e-14 수준이다.
  - 손계산 망 7문제의 중간값과 기울기
  - 계산 그래프 3개, 초기화 표준편차 12개, 활성화 함수 5종 x 160점, Softmax·야코비안 3개, BCE 두 방식 5개(포화 포함), 상대 오차 5개

일부러 틀린 계산(∂L/∂z₂에 1e-6 더하기, Adam 계수 변경)을 넣으면 30건이 실패로 잡히는 것도 확인했다. 그림 배치와 화면 동작은 대조 대상이 아니다. 데스크톱과 375px 폭 브라우저에서 콘솔 오류와 가로 넘침이 없는지 직접 확인했다.
