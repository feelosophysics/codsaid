0. 이 자료를 쓰는 법

PyTorch를 쓸 때 loss.backward() 한 줄 뒤에서 일어나는 일을 직접 만든다. 완성된 학습 루프를 먼저 보고, 그 루프를 돌리는 부품으로 내려간다.

  1. 큰 그림 (20분): 1장에서 이 미션이 「구현 → 검증 → 실험」으로 이어지는 이유를 잡는다. 8장 XOR 실험실에서 초기화를 바꿔 가며 학습을 몇 번 돌려 본다. 아직 원리를 몰라도 된다. "Zero는 왜 안 움직이지?"라는 질문을 들고 내려간다.
  2. 엔진 내부 (60분): 2장의 계산 그래프를 한 단계씩 실행한다. 3장의 연산별 미분 규칙을 코드와 나란히 읽는다. 위젯마다 있는 예측 상자에서 결과를 먼저 말하고 확인한다.
  3. 손계산 (60분, 종이와 계산기): 4장 연습지의 고정 문제를 손으로 풀고 채점한다. "새 문제"로 한 번 더 푼다. 역전파가 손에 익는 단계다.
  4. 검증과 실험 (60분): 5장에서 ε를 바꾸며 수치 미분의 오차를 확인한다. 7장에서 깊은 망의 신호가 폭주하거나 소실되는 모습을 본다. 그다음 실제 실험 결과를 읽는다.
  5. 코드 대조와 설명 연습: 13장에서 요구사항이 어느 파일·테스트로 이어지는지 따라간다. 14장의 질문에 답을 가리고 1분씩 설명한다.
이 미션의 한 문장 요약. 역전파는 "각 연산이 자기 국소 미분만 알고, 엔진은 그 곱을 출력에서 입력 쪽으로 차례대로 전달한다"는 아이디어다. 그 구현이 맞는지는 수치 미분으로 증명한다. 증명된 엔진 위에서는 학습이 실패해도 원인을 엔진이 아닌 다른 곳(초기화, 손실, 학습률)에서 찾을 수 있다.

2. 계산 그래프: 순전파가 그래프를 만들고 역전파가 거꾸로 훑는다

minigrad의 Tensor는 값(data) 말고도 "나를 만든 입력(_prev)"과 "입력에게 기울기를 나눠 주는 규칙(_backward)"을 들고 다닌다. 그래서 연산을 실행하면 그래프가 저절로 생긴다.

필수 개념 계산 그래프 단계 실행: L = (x·y + y)²
예측: y는 그래프에서 두 번 쓰인다(곱셈과 덧셈). 역전파에서 y.grad는 두 경로의 기울기를 어떻게 합칠까?

엔진이 하는 일은 두 가지뿐이다

  1. 위상 정렬: 출력 L에서 _prev를 따라 거슬러 올라가며 모든 노드를 모은다. 그리고 "입력이 출력보다 먼저" 오도록 줄을 세운다. 이 순서를 뒤집으면 "출력에 가까운 노드부터" 순서가 된다.
  2. 역순 호출: L.grad = 1에서 시작한다. 뒤집은 순서대로 각 노드의 _backward()를 한 번씩 부른다. 각 _backward는 자기 out.grad에 국소 미분을 곱해 입력의 grad에 더한다.

순서가 중요한 이유: 노드의 _backward를 부를 때 그 노드의 grad는 이미 완성되어 있어야 한다. 위 예에서 s를 처리하기 전에 L의 기울기가 s로 다 내려와 있어야 한다. 위상 정렬의 역순이 이것을 보장한다.

재귀 대신 스택. 재귀 DFS는 깊은 그래프(예: 5,000번 연속 연산)에서 Python의 재귀 한도(기본 1,000)에 걸린다. tests/test_tensor.py의 test_deep_graph_has_no_recursion_limit가 이 경우를 검사한다.

한 연산의 모양: 덧셈과 곱셈

모든 연산은 같은 틀을 따른다. ① NumPy로 값을 계산한다. ② 입력 중 하나라도 기울기가 필요하면 결과를 그래프에 연결한다. ③ 결과의 _backward에 국소 미분 규칙을 남긴다.

왜 =가 아니라 +=(누적)인가. 같은 텐서가 여러 곳에서 쓰이면 기울기는 경로별 기울기의 합이다(다변수 연쇄 법칙). 위젯의 y가 그 예다. 대입했다면 마지막 경로의 기울기만 남아 틀린 값이 된다. 같은 이유로 매 학습 스텝 전에 zero_grad()로 기울기를 비워야 한다. 비우지 않으면 지난 스텝의 기울기가 계속 쌓인다.

3. 연산별 미분 규칙: 연쇄 법칙이 코드가 되는 곳

각 _backward는 ∂L/∂입력 = ∂L/∂출력 × ∂출력/∂입력의 한 칸이다. 아래 표의 오른쪽 열이 코드에 그대로 적혀 있다.

연산순전파역전파 (g = out.grad)
덧셈c = a + ba.grad += g, b.grad += g
뺄셈c = a − ba.grad += g, b.grad += −g
곱셈c = a ⊙ ba.grad += g ⊙ b, b.grad += g ⊙ a
나눗셈c = a / ba.grad += g / b, b.grad += −g ⊙ a / b²
거듭제곱c = aⁿa.grad += g ⊙ n·aⁿ⁻¹
행렬 곱C = A @ BA.grad += g @ Bᵀ, B.grad += Aᵀ @ g
합s = Σ a (축)a.grad += g를 합친 축 방향으로 복제
exp / logeᵃ / ln ag ⊙ eᵃ / g / a
ReLUmax(a, 0)g ⊙ [a > 0]
Sigmoidσ(a)g ⊙ σ(1 − σ)
Tanhtanh ag ⊙ (1 − tanh²)
Softmaxs = softmax(a)s ⊙ (g − Σ g⊙s)

행렬 곱의 기울기는 shape만 맞춰도 외워진다

C = A @ B에서 A가 (N, K), B가 (K, M)이면 C와 g는 (N, M)이다. ∂L/∂A는 A와 같은 (N, K)여야 한다. (N, M)과 (K, M)으로 (N, K)를 만드는 방법은 g @ Bᵀ 하나뿐이다. ∂L/∂B도 (K, M)을 만들려면 Aᵀ @ g여야 한다.

원소로 확인하면 Cij = Σk AikBkj이다. 그래서 ∂Cij/∂Aik = Bkj이다. Aik는 C의 i행 전체(j = 1..M)에 영향을 주므로 ∂L/∂Aik = Σj gijBkj = (g Bᵀ)ik이다.

브로드캐스팅: 복사된 값의 기울기는 합친다

Linear의 x @ W + b에서 x @ W는 (N, n_out)이고 b는 (n_out,)이다. NumPy는 b를 N개 행에 복사해서 더한다. 순전파에서 값 하나가 N곳에 쓰였으므로, 역전파에서 b의 기울기는 N곳 기울기의 합이다. unbroadcast가 이 합을 맡는다.

b.grad = Σ행 out.grad   — shape (N, n_out) → (n_out,)앞에 추가된 축은 없애며 합하고, 크기 1이던 축은 keepdims로 합한다
예측: 배치 크기를 64에서 128로 바꾸면 b.grad의 크기는? 손실을 배치 평균으로 정의했다면 1/N이 곱해져 크기가 비슷하게 유지된다. 합으로 정의했다면 약 2배가 된다. minigrad의 손실은 모두 평균이다.

4. 손계산 연습지: 2-2-1 신경망 역전파

입력 2개, ReLU 은닉 2개, Sigmoid 출력 1개, BCE 손실이다. 모든 칸을 손으로 채운 뒤 채점한다. 소수 넷째 자리까지 맞으면 정답이다.

z₁ = x @ W₁ + b₁ → h = ReLU(z₁) → z₂ = h · W₂ + b₂ → p = σ(z₂) → L = −[y ln p + (1−y) ln(1−p)]
미리 알아 둘 지름길. Sigmoid와 BCE를 합쳐 미분하면 ∂L/∂z₂ = p − y로 아주 간단해진다. ∂L/∂p = −y/p + (1−y)/(1−p)에 ∂p/∂z₂ = p(1−p)를 곱해 직접 확인해 보라.
손계산 문제 고정 예제
빈칸을 채우고 「채점」을 누른다.
고정 예제 풀이 순서 보기
  1. z₁ = [1·0.5 + 2·0.2 + 0.1, 1·(−0.6) + 2·0.1 + 0.2] = [1.0, −0.2]
  2. h = ReLU(z₁) = [1.0, 0]: 두 번째 뉴런은 꺼져 있다.
  3. z₂ = 1.0·0.8 + 0·(−0.5) − 0.3 = 0.5, p = σ(0.5) = 0.6225, L = −ln 0.6225 = 0.4741
  4. ∂L/∂z₂ = p − y = −0.3775
  5. ∂L/∂W₂ = h · (−0.3775) = [−0.3775, 0], ∂L/∂b₂ = −0.3775
  6. ∂L/∂h = W₂ · (−0.3775) = [−0.3020, 0.1888]
  7. ∂L/∂z₁ = ∂L/∂h ⊙ [z₁ > 0] = [−0.3020, 0]: 꺼진 뉴런으로는 기울기가 지나가지 못한다.
  8. ∂L/∂W₁ = outer(x, ∂L/∂z₁) = [[−0.3020, 0], [−0.6040, 0]], ∂L/∂b₁ = [−0.3020, 0]

두 번째 은닉 뉴런의 기울기가 모두 0인 것을 확인하라. 이 뉴런이 모든 입력에서 꺼져 있으면 영영 학습되지 않는다. 이것을 "죽은 ReLU"라고 한다. LeakyReLU·ELU가 이 문제를 줄인다(12장).

5. Gradient Checking: 역전파가 맞다는 증명

미분의 정의로 돌아가서, 매개변수를 아주 조금 움직였을 때 손실이 얼마나 바뀌는지 직접 잰다. 그 값이 역전파 결과와 같으면 구현이 맞다.

수치 기울기 ≈ [f(x+ε) − f(x−ε)] / (2ε), ε = 1e-5중심차분: 오차 O(ε²)
상대 오차 = ‖ganalytic − gnumerical‖ / (‖ganalytic‖ + ‖gnumerical‖) < 1e-7
필수 개념 ε를 얼마로 잡아야 하나: 절단 오차와 반올림 오차
예측: ε를 계속 줄이면 수치 미분이 계속 정확해질까? float64의 유효 숫자는 약 16자리다.
  • ε가 크면 절단 오차가 커진다. 전진차분은 O(ε), 중심차분은 O(ε²)이다. 테일러 전개에서 홀수 차수 항이 서로 지워지기 때문이다.
  • ε가 너무 작으면 반올림 오차가 커진다. f(x+ε)와 f(x−ε)가 거의 같은 수라 뺄셈에서 유효 숫자가 사라진다. 크기는 약 (기계 정밀도 1e-16)/ε다.
  • 중심차분의 두 오차는 ε ≈ 1e-5 근처에서 균형을 이룬다. 미션의 ε = 1e-5가 그 지점이다. 이때 오차는 약 1e-10 수준이라 기준 1e-7보다 세 자릿수 작다.
  • float32에서는 기계 정밀도가 1e-7이라 반올림 오차만으로 기준을 넘는다. 그래서 minigrad는 float64를 기본으로 쓴다.

상대 오차를 쓰는 이유

절대 오차 |a − n|은 기울기 크기에 따라 의미가 달라진다. 기울기가 1e4인 곳의 오차 1e-6은 아주 정확한 값이고, 기울기가 1e-6인 곳의 오차 1e-6은 완전히 틀린 값이다. 노름으로 나누면 크기와 상관없이 같은 기준을 쓸 수 있다. 원소별로 나누지 않고 텐서 전체의 노름을 쓰는 이유도 있다. 원소별로 나누면 기울기가 거의 0인 원소 하나에서 값이 의미 없이 커진다.

검사를 믿을 수 있게 만드는 장치

  • 무작위 투영: 레이어 하나를 검사할 때 손실을 L = Σ layer(x) ⊙ R로 둔다(R은 고정된 무작위 행렬). 그냥 Σ layer(x)를 쓰면 모든 출력이 같은 기울기 1을 받는다. 그러면 Softmax처럼 출력 합이 항상 1인 레이어의 기울기는 0이 되어 아무것도 검사하지 못한다.
  • 꺾이는 점 피하기: ReLU 입력이 0에서 ε 안에 있으면 x−ε와 x+ε가 꺾임의 양쪽에 걸린다. 그러면 수치 미분이 0.5 같은 엉뚱한 값을 낸다. 구현이 맞아도 검사가 실패한다. 그래서 ReLU 계열 검사 입력은 0에서 0.05 이상 떨어뜨린다.
  • 음성 대조: 일부러 x²의 미분을 2x 대신 x로 틀리게 넣으면, 상대 오차가 정확히 ‖x−2x‖/(‖x‖+‖2x‖) = 1/3이 나와 실패한다. 검사가 버그를 실제로 잡는다는 증거다(tests/test_tensor.py).
  • Dropout: 매 호출마다 마스크가 바뀌면 f(x+ε)와 f(x−ε)가 다른 함수가 된다. 검사 중에는 같은 seed로 마스크를 고정한다.

Softmax: 출력끼리 묶여 있는 레이어

  
ReLU·Sigmoid는 원소마다 따로 계산한다. Softmax는 출력 하나가 모든 입력에 의존한다. 그래서 미분이 행렬(야코비안)이 된다: ∂si/∂zj = si(δij − sj). 이 행렬을 만들지 않고 Jᵀg = s ⊙ (g − ⟨g, s⟩)로 바로 계산하면 C×C 행렬 대신 길이 C 벡터만 쓴다.

7. 가중치 초기화: 학습이 출발하는 자리

  
엔진이 맞아도 출발점이 나쁘면 학습이 실패한다. 실패하는 방식은 세 가지다. 대칭(Zero), 폭주(너무 큰 분산), 소실(너무 작은 분산).


  
7.1 Zero: 대칭성 문제

  
모든 가중치가 같으면 같은 층의 뉴런들은 같은 입력을 받아 같은 값을 내고, 같은 기울기를 받아 같은 만큼 바뀐다. 처음에 같았던 뉴런은 끝까지 같다. 32개 뉴런이 1개처럼 행동하므로 XOR 같은 비선형 문제를 풀 수 없다. 가중치가 모두 0이면 더 나쁘다. ReLU 출력이 0이라 다음 층 가중치의 기울기 hᵀδ도 0이고, 뒤로 가는 기울기 δWᵀ도 0이다. 아무것도 움직이지 않는다.

7.2 분산은 층마다 곱해진다

  
입력 n개를 가중치(분산 σ²)로 섞으면 출력 분산은 n·σ²·Var(x)가 된다. ReLU가 절반을 0으로 만들면 다시 절반이 된다. 층 하나를 지날 때마다 분산이 n·σ²/2배가 되고, L층이면 그 L제곱이다.

Xavier√(2/(n_in+n_out))n/(n_in+n_out) = 0.5표준편차 약 0.7배씩 → 소실

  

  
Xavier는 Tanh·Sigmoid를 위해 만들어졌다. 0 근처에서 기울기가 1(Tanh)이라 절반을 버리지 않는다. 그리고 순전파(n_in)와 역전파(n_out)의 분산을 함께 맞추려고 둘의 평균을 쓴다.

7.4 규모가 커지면 초기화가 결정적이다

  
폭 256, 10층 망에서 층별 활성값과 기울기를 쟀다. Random은 10층에서 활성값 표준편차가 2.6e10까지 폭주했다. Xavier(ReLU)는 0.023까지 소실되었다. He는 0.82에서 0.75로 유지되었다.

  

  
MNIST(입력 784차원) 1 epoch에서는 Random의 첫 loss가 110이었다. 첫 층 출력의 표준편차가 약 √784 ≈ 28배로 커지기 때문이다. 테스트 정확도는 Random 88.0%, He·Xavier 93.8%였다.

9. 옵티마이저: 기울기로 한 걸음

  
옵티마이저는 .data와 .grad가 있는 매개변수 목록만 안다. 레이어 구조를 몰라도 된다.

  

    
방법갱신식성질

    
SGDw ← w − η·g가장 단순하다. 학습률 하나에 민감하다.

    
Momentumv ← μv + g,  w ← w − η·v같은 방향의 기울기를 누적해 골짜기를 따라 가속한다.

    
Adamm ← β₁m + (1−β₁)g,  v ← β₂v + (1−β₂)g²
w ← w − η·m̂/(√v̂ + ε)		매개변수마다 기울기 크기로 나눠 보폭을 맞춘다. m̂, v̂는 0에서 시작한 평균의 편향 보정이다.

    
L2 (weight decay)g ← g + λw손실에 (λ/2)‖w‖²를 더한 것과 같다. 큰 가중치를 매 스텝 조금씩 줄인다.

  

  

  

  
Adam의 첫 스텝은 거의 정확히 η·sign(g)다. t=1에서 m̂ = g이고 v̂ = g²이므로 m̂/√v̂ = ±1이다. 기울기 크기가 3이든 0.001이든 첫 걸음은 η다(test_adam_first_step_is_lr_times_sign). 그래서 Adam에서는 가중치의 초기 크기가 상대적인 변화 속도를 정한다. Random(σ=1)은 He(σ=0.25)보다 같은 η에서 상대적으로 천천히 바뀐다.

  
Adam의 L2 ≠ AdamW. minigrad의 weight_decay는 기울기에 λw를 더한다. Adam은 이 항까지 √v̂로 나누기 때문에, 기울기가 큰 매개변수일수록 감쇠가 약해진다. AdamW는 감쇠를 분리해 w ← w − ηλw를 따로 적용한다. 그래서 보너스 실험의 L2는 SGD + Momentum으로 수행했다.

14. 자기 점검: 미션 목표 다섯 가지

  
답을 펼치기 전에 1분 동안 소리 내어 설명해 본다. 막히면 괄호 안의 장으로 돌아간다.

  
Q1. 계산 그래프는 언제 만들어지고, 역전파는 그 그래프를 어떤 순서로 훑는가? (2장)
    
연산을 실행하는 순간 만들어진다(동적 그래프). 결과 Tensor가 입력을 _prev에, 국소 미분 규칙을 _backward에 기록한다. backward()는 출력에서 그래프를 위상 정렬하고, 그 역순(출력에 가까운 노드부터)으로 각 _backward를 한 번씩 부른다. 역순이어야 노드의 기울기가 완성된 뒤 그 기울기를 입력에게 나눠 줄 수 있다. 같은 노드가 여러 번 쓰이면 기울기는 누적(합)된다.

  
Q2. 수치 미분으로 역전파를 검증하는 원리는? 왜 ε=1e-5, 왜 상대 오차인가? (5장)
    
미분의 정의대로 매개변수를 ±ε 움직여 손실 변화율을 직접 잰다. 이 값은 역전파 코드와 무관하므로 독립된 정답 역할을 한다. 중심차분은 절단 오차가 O(ε²)다. ε가 너무 작으면 뺄셈 반올림 오차가 커진다. float64에서는 ε≈1e-5에서 두 오차가 균형을 이뤄 약 1e-10 수준이 된다. 상대 오차는 기울기 크기와 상관없이 같은 기준(1e-7)을 쓸 수 있게 해 준다. 틀린 구현은 보통 1e-3 이상으로 크게 벌어진다.

  
Q3. 초기화가 기울기 소실·폭주에 미치는 영향을 설명하라. (7장)
    
ReLU 층을 하나 지날 때마다 분산은 n_in·σ²/2배가 된다. 깊이 L이면 이 배율의 L제곱이다. 배율이 1보다 크면(N(0,1): n/2배) 활성값과 기울기가 지수적으로 폭주한다. 1보다 작으면(ReLU에 Xavier: 0.5배) 소실된다. He는 σ² = 2/n_in으로 배율을 정확히 1로 맞춘다. Zero는 분산이 0이라 신호 자체가 없고, 대칭이 깨지지 않아 모든 뉴런이 같게 남는다. 실험에서 10층 ReLU 망의 활성값 표준편차는 Random 2.6e10, Xavier 0.023, He 0.75였다.

  
Q4. 연쇄 법칙은 코드의 어디에서 일어나는가? (2–3장)
    
각 연산의 _backward 안에서 일어난다. 상류 기울기 out.grad(= ∂L/∂출력)에 국소 미분(∂출력/∂입력)을 곱해 입력의 grad에 더한다. 예: 곱셈 self._accumulate(out.grad * other.data). 엔진은 이 곱셈들이 올바른 순서로 일어나게 할 뿐, 미분 공식은 모른다. 그래서 새 연산을 추가할 때는 그 연산의 국소 미분 한 줄만 작성하고 gradient check로 검증하면 된다.

  
Q5. 브로드캐스팅은 기울기 계산에 어떤 영향을 주는가? (3장)
    
브로드캐스팅은 순전파에서 값을 여러 위치로 복사한다. 그러면 역전파에서 그 값의 기울기는 복사된 모든 위치 기울기의 합이어야 한다. 예: (N, 3) + (3,)에서 편향의 기울기는 N개 행의 합이다. unbroadcast가 앞에 추가된 축과 크기 1이던 축을 합쳐 기울기를 원래 shape로 되돌린다. 이것을 빼먹으면 shape가 안 맞아 에러가 나거나, 더 나쁘게는 NumPy가 다시 브로드캐스팅해서 조용히 틀린 값이 들어간다.


  
자주 틀리는 포인트

  
    
    
  • zero_grad()를 빼먹으면 기울기가 스텝마다 쌓인다. 학습률이 점점 커진 것처럼 행동한다.
    • 
    
  • ReLU의 x=0 미분은 정의되지 않는다. 구현은 0을 쓴다. 기울기 검사에서는 그 근처 입력을 피해야 한다.
    • 
    
  • Softmax를 검사할 때 Σ softmax(z)를 손실로 쓰면 항상 1이라 기울기가 0이다. 아무것도 검사하지 못한다.
    • 
    
  • Zero 초기화 실패를 "학습률이 작아서"로 오해하기 쉽다. 학습률을 1000배로 키워도 기울기가 정확히 0이면 아무 일도 일어나지 않는다.
    • 
    
  • Dropout을 켠 채 평가하면 정확도가 낮게 나오고 실행마다 달라진다. 평가 전에 model.eval()을 부른다.
    • 
    
  • MNIST 테스트 세트로 하이퍼파라미터를 고르면 테스트 성능이 낙관적으로 나온다. 검증 세트를 따로 떼어 둔다.
    •
