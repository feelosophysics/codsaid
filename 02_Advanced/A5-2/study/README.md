# A5-2 HTML 학습 자료

`a5-2.html` 하나를 브라우저에서 열면 인터넷 없이 읽고 조작할 수 있다. 그래프·Test 고객 2,000명의 SHAP 값·군집 변환 정보·Python 소스 사본을 모두 파일에 포함했다. 휴대폰 너비(375px)에서도 가로 스크롤 없이 읽을 수 있다.

처음에는 **01 전체 흐름 → 02 데이터 다시 보기**를 읽는다. 02를 먼저 읽으면 "왜 군집이 흐릿한가"와 "왜 SHAP이 세 변수만 고르는가"가 함께 설명된다. 군집화는 03~07장, SHAP은 08~11장, 둘의 연결은 12장, 보너스는 13장이다.

## 포함 내용

- 학습 장 14개, 스스로 설명해 보는 점검 질문과 설명 예시
- 원본에서 자동 발췌한 코드 18개와 실제 줄 번호, 14개 파일 소스 탐색
- 직접 조작 실험 4개
  - 두 고객 사이 거리에서 변수별 비중: 원래 단위 vs 표준화 후
  - K를 하나씩 눌러 K 선택 규칙(1-표준오차 → 안정성 → 구별 변수 수) 따라가기
  - 변수 3개의 Shapley 값을 순서 6가지로 직접 계산하기
  - Test 고객 탐색기: PCA 산점도에서 고객을 골라 SHAP 분해, 페르소나, 판정 보기
- `python -m src.run_all`이 만든 그래프 13개와 해석

점검 질문 체크는 스스로 설명해 봤다는 표시일 뿐이다. 자동 채점이 아니며 새로 열면 초기화된다. 합성 데이터 결과이므로 실제 금융 고객에 대한 결론이 아니다.

## 작성 당시 검증

이 HTML은 작성 당시의 소스·결과로 한 번 만든 학습 자료다. 생성 도구와 템플릿은 정리했고, 아래는 작성 당시 확인한 내용이다.

다음을 검사했다.

- 코드 발췌가 원본의 해당 줄과 같은지, 페이지에 표시된 발췌가 원본과 같은지
- 자리표시자, 내부 링크, 스크립트가 찾는 요소, 입력 레이블, 이미지 대체 텍스트
- 내장 Test 데이터가 결과 파일과 같은지

이어서 Node.js로 페이지의 계산 함수를 실행해 Python 결과와 대조했다. 대상은 다음과 같다.

- Test 2,000명의 군집 재배정 vs scikit-learn K-Means
- PCA 좌표 vs scikit-learn PCA
- 고객별 "기준값 + SHAP 합" vs 모델 점수
- 거리 실험 사례
- Shapley 장난감 사례 vs Python 순열 계산
- K 선택 결과 vs Python `select_k`
