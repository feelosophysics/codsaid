class MiniRedisCLI:

            user_input = input("127.0.0.1:6379> ")

            response = self.engine.execute(cmd, args)

Step 2

메인 코어 엔진 & 오케스트레이션 모듈

mini_redis_core.py

📌 어떤 로직인가

4개 자료구조(HashMap, DoublyLinkedList, MinHeap, HashMap)를 결합하여 [Refinement -> Validation -> Logic Execution] 3단계 파이프라인을 총괄합니다.

🎯 왜 존재하는가

개별 자료구조 부품들을 연결하여 LRU 캐시 교체, 만료 시간 지연 삭제(Lazy Deletion), 바이트 메모리 측정 등 통합 인메모리 엔터프라이즈 로직을 작동시키기 위함입니다.

💡 남에게 설명할 때 핵심 포인트

"모든 커맨드는 먼저 만료된 키를 `_cleanup_expired()`로 청소(Lazy Deletion)한 뒤, maxmemory 도달 시 `_evict_lru()`로 가장 오래된 데이터를 밀어냅니다."

class MiniRedis:
    def set(self, key: str, value: str):
        # 1. 지연 삭제 (Lazy Cleanup)
        self._cleanup_expired()
        # 2. 메모리 한도 검사 & LRU Eviction
        while self._is_oom(key, value):
            self._evict_lru()
        # 3. 자료구조 동시 반영
        node = self.lru_list.add_front(key, value)
        self.store.put(key, node)
Step 3

다항식 롤링 해시 & 체이닝 해시맵

hash_map.py

📌 어떤 로직인가

다항식 롤링 해시공식 H(s)=(sum(s[i]*31^i)) mod (10^9+9)를 사용해 아나그램 충돌을 방지하고, 체이닝 리스트로 데이터를 저장합니다.

🎯 왜 존재하는가

파이썬 dict 없이 O(1) 시간 복잡도로 키-값 저장 및 접근을 가능하게 하기 위함입니다. Load Factor가 0.75에 달하면 2배 재해싱합니다.

💡 남에게 설명할 때 핵심 포인트

"'abc'와 'cba'가 같은 해시를 갖지 않도록 위치별 31의 거듭제곱을 곱해 해시를 생성하며, 충돌 시 버킷 내 체이닝으로 해결합니다."

def _hash(self, key: str) -> int:
    hash_val, p, m, p_pow = 0, 31, 10**9 + 9, 1
    for char in key:
        hash_val = (hash_val + ord(char) * p_pow) % m
        p_pow = (p_pow * p) % m
    return hash_val % self._capacity
Step 4

Sentinel Node 패턴 이중 연결 리스트 (LRU)

doubly_linked_list.py

📌 어떤 로직인가

Head 더미 노드와 Tail 더미 노드를 배치하여 경계 조건 에러 없이 O(1) 시간에 노드 삽입, 제거, 맨 앞 이동을 수행합니다.

🎯 왜 존재하는가

LRU(Least Recently Used) 캐시 순서를 유지하기 위해 사용됩니다. 데이터가 읽히거나 쓰이면 Head(MRU)로 이동하고, 메모리 부족 시 Tail(LRU) 노드를 즉시 제거합니다.

💡 남에게 설명할 때 핵심 포인트

"Sentinel 패턴 덕분에 `if node.prev is None` 같은 예외 처리가 필요 없어 코드가 간결하고 100% O(1) 성능이 보장됩니다."

def insert_front(self, node: Node):
    first = self.head.next
    node.prev, node.next = self.head, first
    self.head.next = node
    first.prev = node
    self._size += 1
Step 5

1차원 배열 기반 완전 이진 트리 최소 힙 (TTL)

min_heap.py

📌 어떤 로직인가

DynamicArray 위에 완전 이진 트리를 얹어 루트(0번 인덱스)에 가장 빠른 (만료시간, 키)를 항상 O(1)로 유지합니다.

🎯 왜 존재하는가

전체 키를 순회하지 않고도 가장 먼저 만료될 항목을 단 O(1) 검사 및 O(log N) 청소하기 위해 존재합니다.

💡 남에게 설명할 때 핵심 포인트

"부모 인덱스 `(i-1)//2`, 자식 인덱스 `2i+1`, `2i+2` 지수 공식을 이용해 pointer 객체 생성 없이 배열만으로 트리를 구성합니다."

def _heapify_up(self, index: int):
    parent_idx = (index - 1) // 2
    while index > 0 and self._data.get(index) < self._data.get(parent_idx):
        self._swap(index, parent_idx)
        index = parent_idx
        parent_idx = (index - 1) // 2
Step 6

고정 크기 버퍼 & 2배 동적 확장 배열

dynamic_array.py

📌 어떤 로직인가

파이썬 내장 list 자동 확장을 쓰지 않고 `[None] * capacity` 고정 배열을 직접 할당받아 `_size` 포인터와 2배 리사이징을 구현합니다.

🎯 왜 존재하는가

모든 자료구조(HashMap 버킷, MinHeap 트리)의 최하단 기초 메모리 빌딩 블록으로 작동하기 위함입니다.

💡 남에게 설명할 때 핵심 포인트

"원시적인 고정 크기 메모리 상자 위에서 Amortized O(1) 요소 추가를 직접 구현한 밑바닥 부품입니다."

def _resize(self):
    new_capacity = self._capacity * 2
    new_data = [None] * new_capacity
    for i in range(self._size):
        new_data[i] = self._data[i]
    self._data = new_data
    self._capacity = new_capacity
