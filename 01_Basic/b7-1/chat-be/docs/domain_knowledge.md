# 건설 용어와 FAQ

챗봇의 질문 주제와 시스템 프롬프트에 사용하는 기초 용어집입니다. 시공·인허가·계약·참여자·자재·개념 비교·플랜트의 일곱 분야를 다룹니다. 법령·현장 기준은 적용 시점의 공식 자료를 함께 확인하세요.

---

## 📚 1. 건설 도메인 7대 카테고리 핵심 용어집 (29개)

### 🔨 1) 시공 / 공정
건축물이 기초부터 완공되기까지 거치는 주요 물리적 공사 단계입니다.

| 용어 | 정의 및 설명 |
| :--- | :--- |
| **골조공사** | 건물의 뼈대(기둥, 보, 슬래브, 내력벽 등) 구조체를 세우는 가장 핵심적인 공사 |
| **마감공사** | 골조가 끝난 뒤 도장(페인트), 타일, 도배, 바닥재 등 표면을 미려하고 기능적으로 마무리하는 공사 |
| **방수공사** | 빗물이나 지하수가 스며들지 않도록 지붕, 옥상, 욕실, 지하 등에 방수재를 처리하는 공사 |
| **조적공사** | 벽돌이나 콘크리트 블록을 모르타르로 한 땀 한 땀 쌓아 벽체를 만드는 공사 |
| **철근콘크리트 (RC)** | 압축력에 강한 콘크리트와 인장력에 강한 철근을 결합하여 일체화시킨 현대 대표 건축 구조 방식 |
| **가설공사** | 공사 기간 중에만 임시로 설치했다가 완공 후 철거하는 시설(외부 비계, 가설울타리, 현장사무소 등) 공사 |

---

### 📑 2) 인허가 / 행정 절차
법규 준수와 안전을 검증받기 위해 관할 관청(지자체)과 진행하는 필수 행정 단계입니다.

| 용어 | 정의 및 설명 |
| :--- | :--- |
| **건축허가** | 건물을 짓기 전, 설계도서 내용이 건축법 및 관계 법규에 적합한지 지자체장으로부터 승인받는 절차 |
| **착공신고** | 건축허가를 받은 후, 실제 공사를 시작하기 전 관할 관청에 공사 착수 일정을 정식 통보하는 절차 |
| **사용승인** | 공사가 끝난 건물이 설계도서대로 시공되어 실제 사람이 안전하게 거주·사용할 수 있는지 확인받는 절차 |
| **준공검사** | 공사가 계약 및 허가 내용대로 완성되었는지 최종적으로 기술적 점검을 수행하는 절차 |

---

### 💰 3) 계약 / 비용
건축주와 건설사 간의 공사 발주, 자금 집행 및 공사비 산출 기준입니다.

| 용어 | 정의 및 설명 |
| :--- | :--- |
| **도급** | 발주자가 시공사에게 일의 완성을 맡기고, 시공사는 일을 완성할 것을 약정하며 대가를 지급받는 계약 |
| **하도급** | 도급을 받은 시공사(원도급자)가 공사의 일부를 제3의 전문건설업체에게 다시 위임하여 맡기는 계약 |
| **평당 공사비** | 건물 연면적 1평(약 3.3㎡)을 짓는 데 소요되는 평균 공사비 (자재, 마감, 입지에 따라 편차 큼) |
| **계약금 / 중도금 / 잔금** | 총 공사비를 계약 체결 시점, 공정 진행 중간 시점, 완공 및 사용승인 시점 세 번에 나누어 지급하는 방식 |
| **견적서** | 공사에 필요한 자재비, 인건비, 경비, 이윤 등을 공종별로 미리 산출하여 발주자에게 제시하는 상세 내역서 |

---

### 👷 4) 참여 주체 역할
건설 프로젝트를 이끄는 5대 핵심 이해관계자입니다.

| 주체 | 역할 및 법적 책임 |
| :--- | :--- |
| **발주자 (건축주)** | 공사를 기획하고 자금을 조달하여 시공사에게 공사를 의뢰하는 주체 |
| **시공사 (건설회사)** | 설계도서에 따라 실제 인력과 자재를 투입하여 목적물을 시공·완성하는 회사 |
| **감리자 (감리원)** | 발주자를 대신하여 공사가 설계도면과 건축법규대로 정확하게 시공되는지 객관적으로 감독하는 전문가 |
| **건축사 (설계자)** | 대지를 분석하고 건축주의 요구에 맞추어 설계도서를 작성하며 인허가 행정을 대행하는 전문가 |
| **하도급업체 (전문건설사)** | 원도급사로부터 특정 전문 공종(창호, 철근, 도장 등)을 위임받아 현장 시공을 직접 수행하는 업체 |

### 🧱 5) 자재 / 구조
건축물을 구성하는 기본 재료와 구조적 형태입니다.

| 자재 / 구조 | 정의 및 특징 |
| :--- | :--- |
| **철근** | 콘크리트 속에 매립되어 인장 강도를 보강하는 고장력 강재 막대 |
| **콘크리트** | 시멘트, 모래, 자갈(골재), 물을 일정 비율로 혼합하여 수화반응으로 경화시킨 인공 석재 |
| **단열재** | 열전도율이 낮은 소재(스티로폼, 글라스울 등)로 건물 내외부의 열 손실을 방지하는 에너지 자재 |
| **방수재** | 우레탄, 아스팔트, 시멘트 액체 등 수분 침투를 막기 위해 바르거나 시트 형태로 붙이는 자재 |
| **조적조 / 철골조 / RC조** | **조적조**: 벽돌·블록을 쌓은 벽식 구조<br>**철골조**: H형강 등 강재 뼈대 구조<br>**RC조**: 철근과 콘크리트를 일체화한 구조 |

### 🔍 6) 헷갈리는 개념 비교
일반인과 초보 실무자가 자주 혼동하는 핵심 개념 대비입니다.

| 비교 대상 | 명확한 차이점 및 핵심 구분 기준 |
| :--- | :--- |
| **신축 vs 리모델링 vs 재건축** | • **신축**: 빈 땅에 새로 건물을 짓는 것<br>• **리모델링**: 기존 건물의 주요 골조를 유지하며 기능·외관을 대수선·개선하는 것<br>• **재건축**: 노후 건물을 완전히 철거하고 바닥부터 새로 짓는 것 |
| **원도급 vs 하도급** | • **원도급**: 건축주(발주자)와 직접 계약을 맺은 종합건설사<br>• **하도급**: 원도급사로부터 특정 공사를 위임받아 수행하는 전문업체 |
| **감리 vs 감독** | • **감리**: 제3자 전문 엔지니어 입장에서 법규·설계도서 준수 여부를 객관적으로 점검<br>• **감독**: 발주자의 지시를 받아 공사 일정, 계약 이행, 현장 행정을 직접 관리 |

### 🏭 7) 플랜트 / 산업설비 건설
에너지 생산 및 산업 생산시설을 짓는 대규모 엔지니어링 분야입니다.

| 용어 | 정의 및 특징 |
| :--- | :--- |
| **플랜트 (Plant)** | 발전, 석유화학, 담수화, 가스처리 등 특정 원료나 에너지를 생산·가공하는 복합 산업 설비 |
| **EPC 계약** | 설계(Engineering), 구매(Procurement), 시공(Construction)을 단일 계약자가 일괄 수행하는 방식 |
| **FEED** | 기본설계(Basic Design)와 상세설계(Detail Design) 사이를 연결하는 단계로, EPC 입찰 견적의 기준이 됨 |
| **화공플랜트** | 원유를 정제(정유)하거나 석유화학 제품(에틸렌, 플라스틱 등)을 대량 생산하는 정밀 화학 공장 건설 |
| **발전플랜트** | 화력, 원자력, 태양광, 풍력, 수소 등 전기 에너지를 대규모로 생산하는 발전소 설비 건설 |
| **턴키 (Turn-key) 계약** | 시공사가 열쇠(Key)를 돌리기만 하면(Turn) 바로 가동할 수 있도록 완성 상태로 인도하는 일괄도급 계약 |

## ❓ 2. 자주 묻는 질문 5선 (FAQ)

### Q1. 리모델링과 재건축은 어떻게 다른가요?
> **답변**:  
> **리모델링**은 기존 건물의 뼈대(기둥, 내력벽 등 기본 골조)를 유지한 채 노후 설비 교체, 평면 확장, 외관 개선을 통해 주거 환경을 개선하는 공사입니다. 공사 기간이 비교적 짧고 인허가 절차가 간소합니다.  
> 반면 **재건축**은 기존 건물을 완전히 철거하고 기초부터 새로 짓는 사업으로, 안전진단 통과 및 정비구역 지정 등 복잡한 법적 절차와 긴 사업 기간이 소요됩니다.

### Q2. 원도급과 하도급은 뭐가 다른가요?
> **답변**:  
> **원도급**은 공사를 발주한 건축주와 직접 도급계약을 체결한 시공사를 의미합니다. 전체 프로젝트의 공정, 품질, 안전에 대한 총괄 책임을 집니다.  
> **하도급**은 원도급사로부터 특정 공종(예: 방수, 창호, 철근배근 등)의 일부를 다시 위탁받아 전문적으로 수행하는 것을 말합니다. 건설산업기본법에 따라 무분별한 재하도급은 엄격히 제한됩니다.

### Q3. 평당 공사비는 어떻게 계산되나요?
> **답변**:  
> **평당 공사비 = 전체 예상 공사비(원) ÷ 건물 연면적(평)**으로 계산합니다.  
> 하지만 평당 공사비는 단순 참고용 지표일 뿐입니다. 지반 상태(토목비용), 지하층 유무, 골조 방식(철골 vs RC), 마감재 등급, 인입 설비(도시가스, 정화조 등) 조건에 따라 실제 견적은 천차만별로 달라집니다.

### Q4. 건축허가와 착공신고는 같은 건가요?
> **답변**:  
> **서로 다른 행정 절차**입니다.  
> • **건축허가**: 공사를 시작하기 전, 설계도면이 건축법 및 지자체 조례에 맞는지 법적으로 승인받는 절차입니다.  
> • **착공신고**: 건축허가를 취득한 후, 시공자·감리자를 지정하고 실제로 공사 삽을 뜨기 전에 관할 구청에 "공사를 시작합니다"라고 알리는 행정 신고 절차입니다. 허가만 받고 착공신고 없이 공사하면 불법입니다.

### Q5. 플랜트 건설과 일반 건설은 어떻게 다른가요?
> **답변**:  
> **일반 건설**은 아파트, 상가, 빌딩 등 사람이 거주하거나 상업 활동을 영위하는 건축물(건축·토목)을 짓는 것이 핵심입니다.  
> 반면 **플랜트 건설**은 정유공장, 발전소, 배터리 공장 등 특정 생산 공정(Process)을 구동하기 위한 복합 산업설비를 짓는 것입니다. 건축물 자체보다 배관, 압력용기, 터빈, 계측제어 등 고도의 기계·화학 엔지니어링 역량이 중심이 됩니다.
